# 竹村翔 個人プロジェクト — Claude Code 設定

## このリポジトリの位置づけ

竹村翔の **個人プロジェクト専用**ワークスペース。
仕事（三幸商事）の repo (`shotakemura-ai/sho`) とは**完全に分離**された私用領域。

| repo | 用途 |
|------|------|
| `shotakemura-ai/sho` | 三幸商事（仕事） |
| `shotakemura-ai/private`（このリポジトリ） | 副業・家計など個人領域 |

両方とも **Claude は1人**。窓口・起動ワード・運用パターンは全て共通。
違うのは「今どの財布（repo）を開いているか」だけ。

---

## 対象プロジェクト

### 副業：AI × BGM
- AI を活用した BGM 制作・配信
- 楽曲制作・リリース管理・収益分析・マーケティング

### 家計管理
- 月次収支管理
- 投資判断補助
- 固定費見直し
- 大型支出計画

---

## コンテキストファイル

- `context/assistant.md` — Claude の自己定義・起動手順・環境ごとのツール表（**最重要**）
- `context/organization.md` — 運用ルール（窓口の使い分け・起動ワード）
- `context/me.md` — 竹村翔の取扱説明書（仕事 repo と共有想定）
- `context/task_templates.md` — 副業・家計用タスクテンプレ集
- `context/learnings.md` — AI 活用の学習ログ

---

## ディレクトリ構成

```
private/
├── CLAUDE.md                 ← 本ファイル
├── context/                  ← Claude への指示・知識
│
├── 副業_AIxBGM/
│   ├── 楽曲制作/             ← AI 生成楽曲のアイディア・プロンプト・成果物
│   ├── リリース管理/          ← Spotify / Apple Music / YouTube の配信状況
│   ├── 収益管理/             ← プラットフォーム別の収益・分析
│   └── マーケティング/        ← 楽曲告知・SNS・サムネ
│
└── 家計管理/
    ├── 月次収支/             ← 毎月の収支まとめ
    ├── 投資/                ← 株式・投信・暗号資産の記録と判断メモ
    ├── 固定費見直し/          ← サブスク棚卸し・通信費・保険など
    └── 大型支出計画/          ← 不動産・車・教育費など
```

## Claude への指示

- **金銭判断は最終的に竹村翔が決定**。AI は選択肢と根拠を提示するに留める
- **家計・投資データは絶対に外部送信しない**（メール下書きで誤って含めないよう注意）
- **副業の収益データも個人情報**として扱う
- 副業に関する税務判断は「税理士に相談を」を必ず添える
- 仕事（三幸商事）と私用が混ざらないよう、このリポジトリには会社情報は持ち込まない
