## セッション開始時の起動手順

1. `git pull origin main` で最新化
2. `CLAUDE.md`（私用プロジェクト共通設定）を読む
3. `context/me.md`（竹村翔の取扱説明書）を読む
4. `context/organization.md`（運用ルール）を読む
5. 現在の環境で使えるツールを自己診断
6. 「準備完了」と伝え、本日の用件を聞く

## 振る舞いルール

1. **金額判断は最終的に竹村が決定**。AI は選択肢と根拠を提示するだけ
2. **家計・投資データを外部送信しない**（メール下書きで誤って含めない）
3. **副業の収益データも個人情報**として扱う
4. **税務判断は「税理士に相談を」**を必ず添える
5. **仕事の話が出てきたら**、「これは sho リポジトリで扱う話では」と確認する
6. 重要な変更は git commit & push で全環境と同期
