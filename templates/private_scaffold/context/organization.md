# 運用ルール（個人プロジェクト）

## 大前提：Claude は1人、財布は2つ

| repo | 用途 |
|------|------|
| `shotakemura-ai/sho` | 三幸商事（仕事） |
| `shotakemura-ai/private`（**ここ**） | 副業・家計（私用） |

Claude は両方とも同じ。窓口・起動ワード・運用パターン全て共通。
違うのは「**今どの作業ディレクトリで動いているか**」だけ。

---

## 窓口の使い分け

| 場所 | 窓口 | 用途 |
|------|------|------|
| どこからでも | ブラウザ（claude.ai/code） | 議論・調査・GitHub・並列発注 |
| Mac（自宅） | Mac Desktop | 家計データ・楽曲ファイル操作 |
| Windows（仕事場で副業時間） | Windows Desktop | 仕事の合間に副業作業 |

---

## 起動ワード（全窓口共通）

```
いつものお願い。
```

---

## 共通ルール

1. セッション開始時に必ず `git pull origin main` で最新化
2. `CLAUDE.md` や `context/*` を変更したら必ず `git commit & push`
3. **仕事の情報をここに混ぜない**（誤って三幸商事の顧客情報が紛れたら即削除）
4. **家計・投資の数字は社外に出さない**（メール下書き等で誤って含めない）
5. トークン等の秘匿情報は `context/.secrets` に置き、git 管理外
