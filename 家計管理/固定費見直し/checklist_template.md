# 固定費棚卸しテンプレート（両学長フレーム適用版）

> 作成日：2026/05/29 ／ 両学長フレーム適用：2026/06/10
> 用途：竹村家計の固定費棚卸し叩き台。数値は本人が後から入力する前提。
> 全体プレイブックは `context/playbooks/ryo_gakucho.md` 参照。

---

## 1. カテゴリ分類（両学長の6大固定費 + 補助カテゴリ）

| # | カテゴリ | 含むもの（例） | 両学長の優先度 |
|---|---------|---------------|----------------|
| 1 | **通信** | スマホ / 自宅回線 / モバイル Wi-Fi | ★★★（最優先・即効性） |
| 2 | **光熱水** | 電気 / ガス / 水道 | ★★（プラン比較で年単位削減） |
| 3 | **保険** | 生命 / 医療 / 火災 / 自動車 | ★★★（過剰加入の宝庫） |
| 4 | **住居** | 家賃 / 住宅ローン / 管理費 / 駐車場 | ★★（一発の効果は最大、ただし腰が重い） |
| 5 | **自動車** | ローン / 任意保険 / 駐車場 / 車検積立 | ★★（保有意義から問い直す） |
| 6 | **税金** | ふるさと納税 / iDeCo / NISA / 各種控除 | ★★★（やらないのは損） |
| 7 | サブスク | 動画 / 音楽 / クラウド / **AI ツール（Claude Pro, ChatGPT Plus, Cursor 等）** | ★★（漏れバケツの代表） |
| 8 | 教育・自己投資 | 書籍 / 講座 / 子供の習い事 | ★（「使う力」寄り、削減対象ではない） |
| 9 | その他 | 会費 / 寄付 / ジム 等 | ★ |

## 2. 見直し優先度ロジック（両学長基準）

両学長の鉄則：**「変動費を節約するより、固定費を一発で見直す」**。
1回の見直しで一生効くものから手をつける。

優先順位：

1. **通信（スマホ・回線）** — 格安 SIM に切替で年5万円規模
2. **サブスク** — 3ヶ月使ってないもの全部解約
3. **保険** — 「死亡・住宅・自動車」の3軸以外は見直し候補
4. **光熱費** — 新電力・新ガス会社のプラン比較
5. **税金（控除フル活用）** — ふるさと納税枠の使い切り、iDeCo/NISA の積立設定
6. **自動車** — 任意保険の見直し・車両保険要否・保有意義
7. **住居** — 一発効果は最大だが腰が重いので最後

## 3. 棚卸しチェックリスト

- **毎月**：クレカ明細・銀行引落の差分確認、新規契約の追記
- **半年に1回**：サブスクの利用ログ確認、AI ツールの稼働状況レビュー
- **年に1回**：保険・通信・住居の総点検、年払い契約の更新タイミング把握

## 4. 削減判断の判定軸

| 軸 | 観点 |
|----|------|
| 金額 | 月額・年額換算でインパクトはあるか |
| 解約難易度 | Web 完結 / 電話必須 / 違約金あり |
| 機会損失リスク | 解約で失う価値（情報・特典・保障）は許容範囲か |
| 家族同意 | 妻・子に影響する契約か（要相談） |
| **両学長基準** | 公的保険＋貯金で代替できる？ → できるなら解約候補 |

## 6. 最初の30分でやること（両学長式・即効性順）

1. **10分** — スマホの契約プランをスクショ → 格安 SIM の同条件プランと比較
2. **10分** — クレカ明細から **未利用サブスク**3つを抽出して即解約
3. **10分** — 加入中の保険一覧を書き出し、「死亡・住宅・自動車」以外を見直し候補にマーク

---

## 7. 保険の見直しチェック（両学長フレーム）

加入中の保険それぞれに以下を問う：

- [ ] **公的保険で代替できる？**（健康保険の高額療養費制度・障害年金・遺族年金）
- [ ] **貯金で代替できる？**（医療費・短期の収入減等）
- [ ] **「起こる確率が低く、損失が壊滅的」リスクに該当する？**（該当しないなら解約候補）
- [ ] **掛け捨て？貯蓄型？**（貯蓄型はインデックス投信に劣後しがち）
- [ ] **契約から3年以上経ってる？**（市場の保険料は下がっている可能性）

判定マトリクス：

| 保険種別 | 両学長の基本姿勢 |
|----------|------------------|
| 定期生命保険（掛け捨て） | 残遺族が必要なら継続。額は再計算 |
| 終身生命保険 | 解約 or 払済を検討（高コスト・低利回り） |
| 医療保険・がん保険 | 原則不要（高額療養費＋貯金で代替） |
| 火災保険・地震保険 | 必要。条件は最適化 |
| 自動車任意保険（対人・対物無制限） | 必要 |
| 車両保険 | 車の価値・支払能力で要否を判定 |
| 個人年金保険 | 解約検討（iDeCo/NISA で代替） |
| 学資保険 | 解約検討（インデックス積立で代替、ただし契約者死亡保障の代替案は別途） |

---

> 保険の見直しで税制・控除が絡む場合は税理士・FP に相談を。
> 解約のタイミングで新規加入できなくなる健康リスクは事前確認を。
