## 2. 見直し優先度ロジック

優先度スコア = **金額の大きさ × 利用頻度の低さ × 解約の易しさ**

1. 金額大 × 頻度低 →【最優先】（眠ってるサブスク等）
2. 金額大 × 頻度高 → 乗り換え検討（通信・保険）
3. 金額小 × 頻度低 → まとめて整理
4. 金額小 × 頻度高 → 後回しで OK

---

## 3. 棚卸しチェックリスト

- **毎月**：クレカ明細・銀行引落の差分確認、新規契約の追記
- **半年に1回**：サブスクの利用ログ確認、AI ツールの稼働状況レビュー
- **年に1回**：保険・通信・住居の総点検、年払い契約の更新タイミング把握

---

## 4. 削減判断の判定軸

| 軸 | 観点 |
|----|------|
| 金額 | 月額・年額換算でインパクトはあるか |
| 解約難易度 | Web 完結 / 電話必須 / 違約金あり |
| 機会損失リスク | 解約で失う価値（情報・特典・保障）は許容範囲か |
| 家族同意 | 妻・子に影響する契約か（要相談） |

```
項目,カテゴリ,月額,年額,利用頻度,解約難易度,見直しメモ,判定
家賃,住居,,,毎日,高,更新月2026/09,継続
楽天モバイル,通信,,,毎日,低,povo比較,減額

```

凡例：
- 利用頻度：毎日 / 週X / 月X / 休眠
- 解約難易度：低・中・高
- 判定：継続 / 減額 / 解約 / 保留

---

## 6. 最初の30分でやること

1. **10分** — クレカ・銀行の直近 1 ヶ月の引落明細をスプレッドシートに貼る
2. **10分** — カテゴリ列を埋める（金額は後回しで OK、まず棚卸し）
3. **10分** — 「3 ヶ月使ってない」サブスクに【解約候補】フラグを立てる

---

> 保険の見直しで税制・控除が絡む場合は税理士・FP に相談を。
