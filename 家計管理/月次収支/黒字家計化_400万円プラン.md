# 黒字家計化 → 400万円積立プラン

> 作成日：2026/06/24（JST）／ブラッシュアップ：2026/07/02
> 関連：`context/playbooks/ryo_gakucho.md`（貯める力）/ `家計管理/価値観マップ_20260624.md`（お金0/10 への一手）

## 3行サマリー

1. **黒字化**（収入 > 支出）→ 2. **生活防衛費 300万** → 3. **特別費 100万** ＝ 当面の砦 **400万**
- 増やす（投資）はその後。バケツの穴を塞いでから水を入れる
- 意志力に頼らない。**先取り・自動振替・口座分け**で仕組み化する

---

## なぜこの順番か（両学長フレーム)

価値観マップで判明：「年収はそこそこあるが全然貯まらない」=漏れバケツ。
だから**増やす（投資）より先に、貯める（黒字化）**。

```
STEP 0  現状把握（数字を出す）        ← イマココ（Mac セッションで実施）
STEP 1  固定費の穴を塞ぐ（黒字化）
STEP 2  生活防衛費 300万を貯める
STEP 3  特別費積立金 100万を貯める
STEP 4  以降は新NISA/iDeCo で増やす力へ（5,000万への道）
```

- **生活防衛費**＝無収入になっても生活できる現金。目安は生活費の6ヶ月〜2年分（会社員寄り6ヶ月／経営者寄り1年以上）。**300万**は月の生活費25〜50万なら 6〜12ヶ月分
- **特別費**＝年に数回の大きな出費（税金・車検・家電買替・旅行・冠婚葬祭・帰省）。別管理しないと**毎月黒字でも年単位で赤字**になる。**100万**はその年間バッファ

## STEP 1：黒字化（穴を塞ぐ）

A − B がマイナス、または黒字額が小さい場合、**固定費から**削る。変動費（食費の節約等）は後回し＝ストレス高・効果低。

### 削減チェック（即効性順）

- [ ] **通信**：大手キャリア → 格安 SIM（年5万円規模）
- [ ] **サブスク**：3ヶ月使ってないもの全解約
- [ ] **保険**：「死亡・住宅・自動車」以外は見直し候補（→ T-406 で棚卸し）
- [ ] **光熱費**：新電力・新ガスのプラン比較
- [ ] **自動車**：任意保険の見直し・車両保険の要否
- [ ] **住居**：最後（効果大だが腰が重い）

※STEP 0 完了後、この順位を**実額に即して**並べ替える（金額インパクト × 手間で優先度決定）。

**目標**：毎月の黒字額を **◯万円**（記入）にする。これが積立の原資。

## STEP 2 & 3：400万円を貯める

### 仕組み化（ここが本体。意志力は使わない）

1. **口座を3つに分ける**：①生活費口座（給与振込）②防衛費口座 ③特別費口座
   - ネット銀行の「目的別口座」機能なら1行で済む（住信SBI・あおぞら等）
2. **給料日翌日に自動振替**を設定：①→②と①→③へ先取り。残った分だけで生活する
3. **積立の順序**：
   - まず **防衛費に全振り**して 100万 まで（最低限の砦を最速で）
   - 100万到達後は **防衛費:特別費 = 7:3** で並行
   - 特別費が 100万 に達したら以降は防衛費のみ → 300万 で完了

### 達成期間の目安

| 毎月の積立額 | 400万までの期間 |
|--------------|------------------|
| 5万円/月 | 約67ヶ月（5年7ヶ月） |
| 10万円/月 | 約40ヶ月（3年4ヶ月） |
| 15万円/月 | 約27ヶ月（2年3ヶ月） |
| 20万円/月 | 20ヶ月（1年8ヶ月） |
| 30万円/月 | 約13ヶ月（1年1ヶ月） |

※既存の現金充当分を差し引いた残額で計算（0-4 の式）。

→ 年間合計が 100万 を大きく超える/下回るなら、特別費の目標額自体を補正する。

### 置き場所（両学長式）

- **生活防衛費300万**：すぐ引き出せる **普通預金 or ネット銀行**（投資に回さない。守りの現金）
- **特別費100万**：同上・**別口座で分離**（混ぜると使い込む）
- **400万達成後の余剰**：ここから初めて新NISA/iDeCo で**増やす力**へ

### やってはいけないこと

- ❌ 400万が貯まる前に投資額を増やす（順序が命）
- ❌ 防衛費・特別費を「一時的に」取り崩す（一時的は一時的で終わらない）
- ❌ 貯蓄型保険・リボ払い・自動車ローンの新規契約
- ❌ 「今月は特別だから」を月2回以上言う（それは特別費の設計ミス。イベント表を直す）

## Claude への運用指示

- このプランは**数字が入って初めて動く**。STEP 0 が埋まったら、達成月数と固定費削減の優先順位を即計算する
- 金額は**人間確認必須**（CLAUDE.md / me.md 準拠）。AI は叩き台
- 税務が絡む判断（役員報酬・経費）は「税理士に相談を」を添える
- 家計の数字は**外部送信メール等に含めない**（個人領域の禁止事項）
- 月末の進捗トラッカー更新時、2ヶ月連続で黒字額が目標を下回ったら**プラン自体の見直し**を提案する（根性論で引っ張らない）

## Mac セッションへのハンドオフ（2026/06/24 引き継ぎ）

**前提**：翔さんはマネーフォワード（MF）で家計管理済み。STEP 0 の数字は MF にある。
**理由**：MF データは個人情報なので、自宅 Mac で扱うのが安全（クラウドセッションには持ち込まない）。

### Mac の Claude がやること

1. このファイルを Read で読む
2. 翔さんに MF を開いてもらい、**集計値だけ**聞き取る。MF 画面との対応：

| このプランの記入欄 | MF で見る場所 |
|--------------------|---------------|
| 0-1 収入 | 家計簿 →「収入」直近3ヶ月の平均 |
| 0-2 支出 | 家計簿 → カテゴリ別支出（固定費は「住宅」「通信費」「保険」等） |
| 0-3 現金性資産 | 資産 → 預金・現金・暗号資産のうち預金合計 |
| 0-3 投資資産 | 資産 → 株式（現物）・投資信託・年金の合計 |
| 0-3 負債 | 資産 → 負債の合計 |

3. STEP 0 の表に**集計値だけ**記入（10万円単位の丸めで十分。生データ・CSV は書き込まない。`.gitignore` で `家計管理/**/*.csv` `*実数*` 等は除外済み）
4. 0-4 の式で **400万達成までの月数**を計算し、進捗トラッカーの「2026-06」行を更新
5. STEP 1 の削減チェックを実額に即して並べ替え、特別費の年間イベント表も埋める
6. 口座3分割 + 自動振替の設定を翔さんに提案（使っている銀行に合わせて具体化）
7. ops_log.md に1行 append（「STEP 0 完了、◯◯ヶ月で400万到達見込み」など）
8. commit & push

### 生データを置く先（git 対象外）

- 明細・カテゴリ別年額・口座別残高など**生に近いデータ**は：
  - `家計管理/月次収支/_actuals/` 配下（`.gitignore` の `*_actuals*` で除外）
  - または Google Drive / OneDrive 等の別管理
- このプランファイル本体には**集計値・判断・アクションだけ**書く

### 完了後、クラウド側に見えるもの

- 集計値の入った 400万プランが push される
- SessionStart hook が ops_log を読み「STEP 0 完了済み」を把握 → どの窓口からでも「次のアクション」を聞ける状態になる
