## なぜこの順番か（両学長フレーム）

価値観マップで判明：「年収はそこそこあるが全然貯まらない」=漏れバケツ。
だから**増やす（投資）より先に、貯める（黒字化）**。バケツの穴を塞いでから水を入れる。

```
STEP 0  現状把握（数字を出す）        ← イマココ
STEP 1  固定費の穴を塞ぐ（黒字化）
STEP 2  生活防衛費 300万を貯める
STEP 3  特別費積立金 100万を貯める
STEP 4  以降は新NISA/iDeCo で増やす力へ（5,000万への道）
```

- **生活防衛費**＝無収入になっても生活できる現金。両学長の目安は「生活費の6ヶ月〜2年分」。会社員寄りなら6ヶ月、自営/経営寄りなら1年以上。**300万**は月の生活費が約25〜50万なら 6〜12ヶ月分に相当
- **特別費**＝固定費でも変動費でもない「年に数回の大きな出費」（税金・車検・家電買替・旅行・冠婚葬祭・帰省）。これを別管理しないと、毎月黒字でも年単位で赤字になる。**100万**はその年間バッファ

## STEP 1：黒字化（穴を塞ぐ）

A − B がマイナス、または黒字額が小さい場合、固定費から削る。**変動費（食費の節約等）は後回し**＝ストレス高・効果低。

### 削減チェック（即効性順）

- [ ] **通信**：大手キャリア → 格安 SIM（年5万円規模）
- [ ] **サブスク**：3ヶ月使ってないもの全解約
- [ ] **保険**：「死亡・住宅・自動車」以外は見直し候補（→ T-406 で棚卸し）
- [ ] **光熱費**：新電力・新ガスのプラン比較
- [ ] **自動車**：任意保険の見直し・車両保険の要否
- [ ] **住居**：最後（効果大だが腰が重い）

**目標**：毎月の黒字額を **◯万円**（記入）にする。これが積立の原資。

## STEP 2 & 3：400万円を貯める（ロードマップ）

黒字額が確定したら、達成までの期間が逆算できる。

| 毎月の積立額 | 400万までの期間 |
|--------------|------------------|
| 5万円/月 | 約67ヶ月（5年7ヶ月） |
| 10万円/月 | 約40ヶ月（3年4ヶ月） |
| 15万円/月 | 約27ヶ月（2年3ヶ月） |
| 20万円/月 | 20ヶ月（1年8ヶ月） |
| 30万円/月 | 約13ヶ月（1年1ヶ月） |

※既に貯金がある分はここから差し引ける。

### 置き場所（両学長式）

- **生活防衛費300万**：すぐ引き出せる **普通預金 or ネット銀行**（投資に回さない。守りの現金）
- **特別費100万**：同上 or 別口座で分離管理（混ぜると使い込む）
- **400万達成後の余剰**：ここから初めて新NISA/iDeCo で**増やす力**へ

## Mac セッションへのハンドオフ（2026/06/24 引き継ぎ）

**前提**：翔さんはマネーフォワード（MF）で家計管理済み。STEP 0 の数字は MF にある。
**理由**：MF データは個人情報なので、自宅 Mac で扱うのが安全（クラウドセッションには持ち込まない）。

### Mac の Claude がやること

1. このファイルを Read で読む
2. 翔さんに MF を開いてもらい、以下を**集計値で**聞き取り（生データ・CSV はこのプランファイルに**書き込まない**。`.gitignore` で `家計管理/**/*.csv` `*実数*` 等は除外済み）：
   - 月の収入（手取り平均、直近3ヶ月）
   - 月の支出（平均）と、固定費 TOP5 の内訳
   - 現金性資産の合計（普通・定期・ネット銀の合算）
   - 投資資産の合計（NISA/iDeCo/特定の評価額）
   - 負債（住宅ローン残高・カード未払）
3. STEP 0 の表に**集計値だけ**記入（10万円単位の丸めで十分）
4. 黒字額から **400万達成までの月数**を計算し、進捗トラッカーの「2026-06」行を更新
5. 削るべき固定費の優先順位を、両学長フレーム（通信→サブスク→保険→光熱→自動車→住居）で**翔さん家計の実額に即して**並べ替え
6. ops_log.md に1行 append（「STEP 0 完了、◯◯ヶ月で400万到達見込み」など）
7. commit & push

### 生データを置く先（git 対象外）

- 詳細な明細・カテゴリ別の年額・口座別残高など、**生に近いデータ**を残したい場合：
  - `家計管理/月次収支/_actuals/` ディレクトリ配下に置く（`.gitignore` の `*_actuals*` で除外される）
  - または Google Drive / OneDrive 等の別管理
- このプランファイル本体には**集計値・判断・アクションだけ**書く

### 完了したらクラウド側（このセッション継続）に何が見えるか

- 集計値の入った 400万プランが main に push される
- 次回どこからセッションを開いても、SessionStart hook が ops_log を読んで「STEP 0 完了済み」を把握する
- → 翔さんはどこからでも「次のアクション」を僕に聞ける状態になる
