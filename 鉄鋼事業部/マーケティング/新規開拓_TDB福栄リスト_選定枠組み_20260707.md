# TDB＋福栄リスト — 候補一覧化と優先順位付けの枠組み（叩き台）

> 作成: 2026-07-07（Claude）／ Asana「TDB＋福栄リストで候補を一覧化→優先順位付け」（89期マンダラ ④増やす・期日6/30超過）
> 前提メモ: 「経営企画室サポート→竹村選定」。リスト実物は repo / Drive に見当たらないため、
> **リストが届き次第すぐ回せる「選定の型」**を先に用意した。リストを共有いただければ Claude が仮スコアまで自動でやります。

---

## 進め方（3ステップ・竹村の作業は最終選定だけ）

1. **受領**: 経営企画室から TDB リスト＋福栄リストを CSV / Excel で受領（Drive 共有でOK・repo には置かない）
2. **仮スコア**: Claude が下の基準で全件スコアリング → 上位20社に絞った一覧表を提示
3. **選定**: 竹村が最終10社を選ぶ → 担当割当・アプローチ順を決めて Asana 化

## スクリーニング（1次足切り）

- 地域: 関西・中部・関東（訪問可能圏）を優先。それ以外は「遠隔」タグ
- 業種: 製缶・金属プレス・印刷・雑貨/ノベルティ・玩具、および薄板/ブリキの需要が見込める加工業
- 与信: TDB 評点 **50点以上**を基本線（50未満は要相談枠へ）

## スコアリング表（各1〜5点・合計25点満点）

| 軸 | 見るポイント |
|----|-------------|
| 需要適合 | 当社取扱品目（ブリキ薄板・鋼板・缶バッジ資材）との一致度 |
| 規模ポテンシャル | 年商・従業員数から見た月間取引の伸びしろ |
| 与信 | TDB 評点・業歴・財務傾向 |
| 戦略適合 | ダイキ撤退カバー／電炉ぶりき（ほぼゼロ）拡販との連動性 |
| 攻めやすさ | 既存顧客・仕入先からの紹介経路、地理的近さ、EC接点の有無 |

## 一覧化テンプレ（この列で表を作る）

社名｜所在地｜業種｜年商/従業員｜TDB評点｜想定品目｜スコア(25)｜優先度(A/B/C)｜想定アプローチ｜担当
