# /shodan-mae — 商談前キット（らすく式「面談前キット」の鉄鋼商社版）

翔さんがやるのは「明日○○社」の一言だけ。**聞き返すのは相手先が特定できない時だけ。**
成果物は A4 1枚。読むのに3分、相手の前で困らない材料が全部載っている状態にする。

## 0. 準備
1. `TZ=Asia/Tokyo date '+%Y-%m-%d (%a)'` で今日を確定
2. context/me.md・context/preferences.md・context/conversation_topics.md（鉄則と NG の節）を読む
3. **相手先と日時を特定する**（この順で・分かった時点で止める）
   - 引数／発言に会社名・日時があればそれ
   - Google カレンダーを会社名で検索（今日〜14日先）。見つかれば日時・場所・説明欄を取る
   - 見つからなければ「○○社で合ってますか？日時は？」と**1回だけ**聞く
4. 文脈を判定：鉄鋼（ブリキ・鋼板・海外ミル・商社）か、缶バッジ（キャラバン・EC・OEM）か。保存先が変わる

## 1. 集める（内と外を分ける。並列でよい）

### 内（本体がやる。顧客情報を扱うので調査班には渡さない）
| 何を | どこから | 取り方 |
|------|---------|--------|
| 基本情報・担当者 | `context/customers.md` | 会社名で grep。無ければ「未登録」と記す（後で /shodan-ato が育てる） |
| うちとの直近のやり取り | Gmail | 会社名・ドメイン・担当者名で過去90日を検索。スレッド上位5件を開き「何が決まって・何が未決か」を各1行に |
| 進行中の案件・宿題 | Asana | 会社名で検索。期限・担当・状態を1行ずつ |
| 過去の商談記録 | `鉄鋼事業部/営業/商談メモ/`・`缶バッジ事業部/営業/` | 会社名で grep。前回の議事録・宿題があれば「前回の宿題は果たしたか」を確認項目に入れる |
| 過去の会議録 | Zoom for Claude（`zoom_my_notes`／`zoom_meeting`）を会社名で検索。Plaud の MCP がこのセッションにあればそれも | 直近1件の要点と宿題 |
| 今動いている判断 | `経営企画室/レポート/判断キュー/判断キュー_最新.md` | 相手先が載っていれば🔴🟠の該当行を引く |
| 前回のメンター FB | `経営企画室/レポート/メンターFB/` | 相手名・場面で grep。直近1件の「次回の一手」をキットの冒頭に1行再掲（`/mentor` の約束を次の商談で試す） |

### 外（調査班 `chosa-han` に Agent で委託。渡すのは会社名・業種・所在地・面談の一般的な目的だけ。金額・数量・社内の経緯・担当者名は渡さない）
依頼文の型：
```
○○株式会社（業種：△△、所在地：□□）について、商談前の仕込み用に以下を調べて出典 URL 付きで返してください。
1. 直近3ヶ月の同社ニュース・プレスリリース・IR・人事（あれば）3点以内
2. 同社の業界で今週話題のこと（規制・需給・価格・原料）2点以内
3. 会話の切り出しに使える時事3点（スポーツ・地元・経済。関西の取引先なら阪神を必ず1つ）
各項目1〜2行。推測は「推測」と明記。個人（担当者個人）のSNS等は調べない。
```

## 2. キットの形（この順・A4 1枚・見出し固定）
```
# ○○社 事前キット — YYYY-MM-DD(曜) HH:MM @場所
> 作成: Claude（/shodan-mae）／出典は各行末尾。数字は要確認。

## 1. この商談のゴール（1行）
## 2. 相手の直近動向（3点・出典付き）
## 3. うちとの経緯・未決事項（メール／Asana／前回議事録から。各1行）
## 4. 当日確認すること（チェックボックス5つまで。前回の宿題を必ず1つ入れる）
## 5. 相手が聞いてきそうなこと → 答えの方向（3つ。数字が要るものは「持参資料参照」と書き、ここで数字を作らない）
## 6. 会話ネタ（3つ。相手の出身・地元・共通の知人があれば優先）
## 7. 言わないこと（仕入価格・原価・他社の悪口・スポット推奨。conversation_topics の NG から相手に該当するもの）
## 8. 持ち物・資料（あれば）
```
- **数字（単価・数量・納期）はキットに書かない。** 書く必要があるときは「持参資料 p.X」「Asana 参照」に逃がす。どうしても載せるなら検算班 `kensan-han` を通してから
- 推測は「（推測）」を付ける。出典の無い事実を作らない
- 文体：本質を突いた簡潔さ。1行20字〜40字。回りくどい表現禁止

## 3. 保存と報告
- 保存先：鉄鋼なら `鉄鋼事業部/営業/商談メモ/YYYYMMDD_<会社名>_事前キット.md`、缶バッジなら `缶バッジ事業部/営業/商談メモ/`（無ければ作る）
- 翔さんへの報告は**5行以内**：ゴール1行・確認事項の上位2つ・会話ネタ1つ・ファイルの場所・「数字は載せてません」
- `context/ops_log.md` に1行 append（例：`| YYYY-MM-DD | 鉄鋼 | ○○社 事前キット | 1 | /shodan-mae |`）
- コミット＆push（現在のブランチ）。失敗しても止まらない

## やらないこと
- メール送信・カレンダー変更・Asana 更新（読み取りだけ）
- 担当者個人の SNS・私生活の調査
- 「頑張ってください」系の励まし文。必要なら context/sbt.md の「成功イメージ」を1行だけ（翔さんが会食・大型商談と言った時に限る）

## 例
- 「明日 JETRO の面談」→ カレンダーで 9/28 10:00 を特定 → Gmail で上田様スレッド → Asana「JETRO 企業リストアップ申込」→ 調査班に JETRO 大阪の最新支援メニュー → キット保存 → 5行報告
- 「来週キャラバン行く」→ 缶バッジ文脈 → Asana『キャラバン受注管理』の進行中案件 → 判断キューの🟠 → 缶バッジ事業部/営業/商談メモ/ に保存
