# /codex — 設計は Claude、実作業は Codex、検品はまた Claude

らすく式 AI チーム編成の実装。**翔さんが Codex を開くことはない。**
Claude（Fable）が図面を引く → Codex（職人）が作る → Claude が検品して翔さんに渡す。

## 0. 使える状態かを確認する（毎回・黙って）
- このセッションに `mcp__codex__*`（`codex` / `codex-reply`）ツールがあるか確認
  - **ある**（Mac／会社 PC の Desktop アプリ）→ 続行
  - **ない**（クラウド／Routine／未接続の PC）→ 翔さんに1行：「この端末は Codex 未接続です。Claude だけで進めます（画像は仕様書まで）」。設計・文言・仕様書は作り、画像生成だけ PC でやれる形（下の「仕様書」）を残して止まる
- 初回接続は翔さんが PC で `npm install -g @openai/codex` → `codex login`（ChatGPT Business）。設定は repo の `.mcp.json` が持っているので、それ以上の手順はない

## 1. 何を Codex に任せるか（任せないか）
| 任せる | 任せない（Claude がやる） |
|---|---|
| 画像生成（SNS 画像・EC バナー・提案書の図解・アイコン） | 文章の判断・顧客対応・見積・数字の入る文書 |
| コードの実装・修正（経費精算スクリプト等）※必要になった時だけ | 設計・要件の整理・最終チェック |
| Claude の利用上限に当たった時の「代打」（下記 §4） | 翔さんとの壁打ち |

## 2. 渡す前の検問（機密が外に出ない構造）
Codex に渡すプロンプトには次を**含めない**。含めないと成立しない依頼は Codex に出さず、Claude 単体でやる。
- 顧客名・担当者名・取引先のメール本文・Asana の中身
- 単価・数量・納期・仕入価格・原価・売上・家計の数字
- 社内メンバーの個人情報・健康・評価
- 秘密 URL・トークン・パスワード

画像の依頼なら：用途（X／Instagram／EC／提案書）・サイズ・雰囲気・入れる文字（商品の一般名は可。顧客の IP・キャラクター名は**権利上も渡さない**）・禁止事項（「世界初」等の表現 NG は `缶バッジ事業部/SNS/` の運用メモ準拠）。

## 3. 手順
1. **仕様書を Claude が書く**（5〜10行）：目的／成果物の形式とサイズ／必須要素／NG／保存先／出来の判定基準
2. `codex` ツールに仕様書を渡す。作業ディレクトリは repo。Codex にも `AGENTS.md` を読ませる（自動で読む）
3. 返ってきたら **Claude が検品**：仕様との差分・文字化け／誤字・禁止表現・保存先・ファイル名（`YYYYMMDD_<用途>_<連番>.png`）。ダメなら `codex-reply` で差し戻し（最大2周）
4. 画像は翔さんに見せる（パスと1行説明）。**SNS 投稿・EC 掲載は翔さんの OK 後**（起案班のルールと同じ。送信・公開は人間）
5. `context/ops_log.md` に1行（例：`| YYYY-MM-DD | 缶バッジ | X 用画像 3案（Codex） | 1 | /codex |`）、コミット＆push

## 4. 「代打」の使い方（Claude の上限に当たった時）
正直に書くと、**Claude が止まっている間は、このスキル自体も動きません**（呼び出し元が Claude なので）。代打の実体は次の2つ：
- **事前の節約**：長い実行作業（画像を何案も作る、スクリプトを書く）を Codex に振ると、Claude 側の消費が減って上限に当たりにくくなる
- **止まった時**：翔さんが PC で Codex を直接開く。`AGENTS.md` が `CLAUDE.md` と同じルールを読ませるので、Claude と同じ前提で動く。やった内容は Codex が ops_log に1行残し、Claude 復帰後に検品する
つまり上限対策は「Codex を Claude の中で使う」より「**同じ記憶（repo）を両方が読む**」ことで成立している。

## やらないこと
- 顧客情報・数字入りの依頼を Codex に流す
- Codex の成果物を検品せずに翔さんに渡す／公開する
- Codex が無い端末で「できました」と言う（できていないことは言う）

## 例
- 「缶バッジマシンの X 投稿用に秋っぽいバナー3案」→ 仕様書（1200×675・商品名は一般名・文字は『秋の新色』・世界初 NG）→ codex → 検品 → `缶バッジ事業部/SNS/画像/20260925_X秋バナー_01.png` ほか3枚 → 翔さんに提示 → OK で投稿文を起案班へ
