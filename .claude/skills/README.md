## つながり（どのスキルがどのスキルを呼ぶか）
- 文章を作るスキル（mail-ops・kian-han・design-studio・shodan-ato・mitsumori）→ 書く前に `/buntai`
- `/kikaku` の設計シートが OK → 詰めるなら `grill-me`、資料は `bumon-pres`／`design-studio`、図解は `/codex`、迷ったら `/handan`
- `/handan` で「重い」と判定 → `virtual-board`
- `/getsuji` の「来月の重点3つ」→ 月初の朝刊（R-daily）が再掲
- どのスキルでも翔さんの指摘が出たら `/oboete`

## 運用ルール
- スキルは「繰り返す仕事」を1つずつ言葉にしたもの。**新設は既存が2週間使われてから**（増築禁止。2026-09-25 の④系4本は本人指示による例外）
- スキルの手順にミスがあったら、その場で `/oboete` → 該当 SKILL.md に1行足す（失敗をルール化）
- 送信・Asana 書き込み・カレンダー変更は、どのスキルも翔さんの OK 後
- 2週間使われなかったスキルは R-weekly が「捨てる／統合する」候補に挙げる
