## 運用ルール
- スキルは「繰り返す仕事」を1つずつ言葉にしたもの。**新設は既存が2週間使われてから**（増築禁止）
- スキルの手順にミスがあったら、その場で `/oboete` → 該当 SKILL.md に1行足す（失敗をルール化）
- 送信・Asana 書き込み・カレンダー変更は、どのスキルも翔さんの OK 後
