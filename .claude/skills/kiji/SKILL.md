# /kiji — 記事・報告書の一気通貫（情報発信系）

らすく式「開催の翌日には記事が公開できる」の実装。翔さんがやるのは**素材を渡す・推敲する・公開ボタン**の3つだけ。
速度優先：**翌日に60点で出す**。磨くのは出した後（最上志向の落とし穴補正・strengths.md）。

## 0. 準備（黙ってやる）
1. `TZ=Asia/Tokyo date '+%Y-%m-%d'`。**出口を判定**（引数・話題から。迷ったら1問）：
   | 出口 | 読者 | 保存先 | 形式 |
   |---|---|---|---|
   | A. badge-koi マガジン記事 | 缶バッジのお客さま・見込み客 | `缶バッジ事業部/SNS/記事/YYYYMMDD_<題名>/` | Gutenberg ブロック HTML（design-studio「道B」：冒頭に貼付手順コメント→翔さんがコードエディタに貼る） |
   | B. 社内共有レポート | 社長・役員・部下 | `経営企画室/レポート/YYYYMMDD_<題名>.md`（出張報告は docx も） | md（＋docx/pptx は bumon-pres の型） |
   | C. 顧客向け資料 | 特定の取引先 | `鉄鋼事業部/営業/` or `缶バッジ事業部/営業/` の該当社フォルダ | md→html/pdf |
2. 素材を集める：Plaud（`list_files`→`get_transcript`）／Zoom ノート／貼り付け／写真フォルダ（`ls` で確認）／関連する過去記事・報告書（同じ題材を grep して重複を避ける）
3. `/buntai` の場面ルールを当てる（A＝C 場面：写真主役・控えめ敬語、B＝社内文書：結論先行・数値、C＝社外：長い付き合いの続き）

## 1. 流れ（止まらずに通す。翔さんの OK を取るのは★の1回だけ）
1. **文字起こし→要点**：発言を「事実／決定／宿題／数字／良い一言（引用候補）」に仕分け
2. **骨子（見出し5つ以内＋各1行）** ★大型（A4 3枚超・顧客向け）ならここで翔さんに1画面で見せて OK を取る。小型は止まらない
3. **本文**：結論→背景→数値の順（B・C）。A は「読者の困りごと→答え→写真→一言」。数字は根拠つき、置けない数字は書かない
4. **図解の配置判断**：本文を読み直し「文章より図の方が早く伝わる箇所」を**最大3つ**選ぶ。各箇所に「図の種類（比較表／流れ／数字1つ強調）・入れる文言・サイズ」を1行で指定
5. **図解・アイキャッチ**：`/codex` に4の指定と本文の該当段落を渡して生成（顧客情報・価格は渡してよい。顧客 IP 画像・認証情報は渡さない）。Codex が使えなければ図解は「後で」と印を付けて先に進む（止まらない）
6. **納品形式に整える**：A＝Gutenberg HTML（design-studio 道B）／B＝md（必要なら docx）／C＝md＋html。画像はファイル名を `YYYYMMDD_<用途>_<連番>.png` で保存し、本文からの参照を確認
7. **公開後の整備（A のみ・提案止まり）**：関連する既存記事へのリンク案3つ、X 告知文1本（design-studio の運用5ルール）、次の記事ネタ1つ
8. **検品**：一度通読。仕入価格・原価・社員の繊細情報・他社名の写り込み・AI の痕跡（「AI が」「自動で」）が無いか。金額・数量・納期があれば `kensan-han`（B・C）と「⚠人間確認必須」

## 2. 報告（1画面）
```
## /kiji <出口>：<題名>（YYYY-MM-DD）
- 成果物：<パス>（本文 ○字・図解 ○点）
- 翔さんの残作業：推敲 → 公開/送付（A は WordPress に貼る・B は共有・C はメール添付）
- 図解「後で」：○点（Codex 未接続のため）
- 提案：関連リンク3・告知文1・次のネタ1（A のみ）
```

## やらないこと
- 公開・投稿・送付・共有ドライブへの配置（翔さんがやる。MCP/REST 経由の WordPress 自動投稿は禁止＝design-studio の確定事項）
- 素材に無い事実・数字を足す。開発中の全自動機など掲載禁止の素材を使う（design-studio の機材ルール）
- 骨子の OK を待って止まる（小型は止まらず完成品まで進める）
- 出典の無い引用。個人（相手担当者）の発言をそのまま公開記事に載せる（B・C は要点化、A は許可のある声だけ）

## 例
- 翔さん「昨日の郡上出張、報告書にして」→ 出口 B → Plaud の該当2件＋写真フォルダ → 骨子（訪問先2社・決定・宿題・数字）→ 本文 → 図解1（訪問先別の要点比較表）→ `経営企画室/レポート/YYYYMMDD_出張報告書_郡上.md`（＋docx）→ 数字は検算班 → 報告1画面
- 翔さん「工場見学の様子をマガジン記事に」→ 出口 A → 写真フォルダ＋当日メモ → 骨子 → 本文（写真主役）→ 図解2＋アイキャッチ（/codex）→ Gutenberg HTML → 関連リンク3・告知文1
