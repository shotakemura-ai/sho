# 僧侶 v7.6後期 — 完全版カスタマイズ

> **基準日**: 2026-05-10  
> **対象**: ドラゴンクエストX Ver.7.6後期  
> **主戦場**: エンドコンテンツ  
> **位置づけ**: 本ファイルは僧侶の **標準回答（キャノニカル）**。他職もこの深度で書く。

## エグゼクティブサマリ

Ver.7.6後期の僧侶は、公式調整で **バギ系呪文の追加 / 聖女の天蓋・ホップストリームの実装 / しんこう心・スティック・棍の強化 / 聖女の守りの戦域・キラキラポーンの戦域・ホップストリームの戦域の3新宝珠** を受けて、従来どおり「回復と生存」を主軸にしつつ、暇ターンには一定の攻撃貢献も可能になった。とはいえ公式・現行攻略ともに、僧侶の最優先は **回復・蘇生・補助・自衛 → 攻撃はその後** で一致している。

総合結論を先出しすると、

- **1セット運用の本命**: ピュアリィタクト or ルーナステッキ ＋ アクエリアスガード／メテオシールド持ち替え ＋ ロードリーローブ
- **2セット目を持つなら**: 非ブレス100前提での **叡聖差し替え**
- **アクセ汎用軸**: 神智のゆびわ・アヌビスのアンク・不思議のカード・紫竜の煌玉・ブエルの大紋章・リナーシェのこころ
- 顔・首・証はボスごとに差し替え

160〜200Pの選択式スキルは、回復本体としては **聖女の天蓋II・ホップストリームIII・アイギスの守りIII・被ダメージ10軽減・呪文回復量+20** を優先し、しんこう心200は **復活時早詠みの杖75%** を本命にするのが最も安定。極限攻略は、復活時の **聖なる祈り** と **早詠みの杖** を立て直し向きと評価し、逆に **復活時天使の守り／女神の祝福は200でも10%で当てになりにくい** と明言。

バトルコマンドは、7.6後期僧侶の本質である **事故防止** を最優先に組む。**聖なる祈り・聖女の守り・キラキラポーン・天使の守り・アイギスの守り・聖女の天蓋・ホップストリーム を1ページ目に集中**、攻撃や低優先度は2ページ目以降または非表示。**開幕天使は悪手寄り**で、基本は **祈り先行**。

僧侶の「最強」は厳密にはボスごとの必要耐性とダメージラインで変わる。同じ部位で積める耐性は競合するため、**体上・体下・頭・足の一部耐性錬金と、首・顔・証・他アクセの一部差し替えは『未指定』** とし、代わりに「汎用本命」と「差し替え本命」を明示する。

```
                     └─ はい ── バギムーチョ or ホーリーライト
```

このフローは **回復・蘇生・補助の三本柱**、**聖なる祈りの維持**、**攻撃は暇なときだけ** という現行方針を操作順に落とし込んだもの。

### 開幕

基本は **位置取り → 聖なる祈り → 最初の防御補助**。

| 敵の初動 | 差し込み |
|---|---|
| ブレス寄り | フバーハ |
| 物理寄り | スクルト |
| ジャンプ回避を通したい | ホップストリーム |
| 状態異常主体 | キラキラポーン |

自分への天使の守りはその後。**戦闘開始後すぐの天使は悪手寄り**。

**開幕の汎用例**:
```
聖なる祈り → フバーハ or スクルト → 前衛に聖女の守り
→ 自分に天使の守り → 余裕があればホップストリーム or 聖女の天蓋
```

7.6後期では **女神の祝福の初回CTが0秒** になっているため、最初の大技が見えているボスでは **天使より先に女神** の選択も十分あり。

### 基本ループ

通常時のループ順：**祈り維持 → HP管理 → 蘇生 → 補助 → 自衛 → 攻撃**

- 全体被弾はベホマラー、単体被弾はベホイム
- 祈りが切れそうなら攻撃や補助より祈り優先
- ベホマラーはベホイムより回復量が低くMP消費も重いので **使い分けが重要**
- 蘇生はザオラル優先だが、複数人削れているなら **先ベホマラー → 後ザオラル**
- 他メンバーが蘇生できる状況では、僧侶は蘇生を任せて回復優先がよい場合あり

### 聖女の天蓋の運用

7.6後期の新技 聖女の天蓋は強いが CT も重い。**「見えた危険」に切るボタン**：

- 複数人が次の1発で落ちる場面
- 次の行動が明確に即死級と分かっている場面
- 立て直し直後で全体に保険をばらまきたい場面

**開幕から雑に切るボタンではない**。

### 優先順位

| 優先順位 | 判断 | 基本行動 |
|---|---|---|
| 最優先 | 自分が死なないか | 位置取り、アイギス、天使、まもりのたて |
| 次点 | 祈りが切れていないか | 聖なる祈り |
| 次点 | 味方が今すぐ落ちるか | ベホマラー / ベホイム / 聖女 |
| 次点 | 死人がいて回復が足りているか | ザオラル |
| 次点 | 次の大技を防げるか | 聖女の天蓋 / ホップストリーム / キラキラポーン |
| 余裕時 | MP・CT・長期維持 | スピリットゾーン / マホトラのころも |
| 最後 | 暇ターン | バギムーチョ / ホーリーライト |

### NG行動

- **開幕天使先行**：現行解説で悪手寄り
- **祈り切れを放置したままベホマラーを撃ち続ける**：僧侶の強みを自分で潰す
- **単体被弾に毎回ベホマラー**
- **聖女の天蓋を何となくで切る**
- **味方のHPが不安定なのに攻撃へ回る**
- **神智のゆびわを耐性指輪に固定する**：ボス固有事情がない限り避ける

### 具体的な行動例

#### 全体ブレス＋単体大技型
```
聖なる祈り → フバーハ → 前衛へ聖女の守り → 自分へ天使の守り
→ 被弾後ベホマラー → 次の大技前に聖女の天蓋
```
**聖女の天蓋は「削られた後」ではなく「次の落下ラインが見えた前」で切る**方が強い。

#### ジャンプ回避ギミック型
```
聖なる祈り → ホップストリーム → 通常回復 → 更新タイミング前に再ホップ
```
7.6後期はホップストリーム本体と宝珠の両方で使い勝手UP。ジャンプ技が頻出する敵では最優先補助の一つ。

#### 崩れかけた立て直し
```
ザオラル → ベホマラー → 自分に天使の守り → 危険者へ聖女の守り
→ 余裕があれば聖女の天蓋
```
復活時早詠みや復活時祈りが絡んでいれば、リカバリーはさらに速い。

#### 暇ターンの攻撃参加
祈り残時間に余裕 / 全員安全 / 次行動の危険が見えていない なら、**バギムーチョ または ホーリーライト**。

ただし僧侶は **「攻撃しても壊れない時だけ攻撃する職」**。この一線は7.6後期でも変わらない。
