# 職別 確定情報ベース

各職について `{職名}.md` を `_template.md` ベースで作成し、
確定情報（最新装備名・宝珠名・スキル振り・コマンド配置）を蓄積する。

## ファイル名規則

職名はかな・カナ表記で統一：
- `戦士.md`
- `武闘家.md`
- `僧侶.md`
- `魔法使い.md`
- `バトルマスター.md`
- `パラディン.md`
- `レンジャー.md`
- `賢者.md`
- `スーパースター.md`
- `まもの使い.md`
- `踊り子.md`
- `占い師.md`
- `天地雷鳴士.md`
- `魔剣士.md`
- `海賊.md`
- `デスマスター.md`
- `まほうつかい.md`
- `遊び人.md`
- `盗賊.md`
- `旅芸人.md`
- `ガーディアン.md`
- （以下、実装済みの職全て）

## 運用

1. 質問対応で得た情報をその職のファイルに追記
2. 古くなった情報は「※v7.X時点」と注記して残す（履歴として有用）
3. WebFetchで確認した出典URLを必ず添える
4. バージョン更新時にレビュー
