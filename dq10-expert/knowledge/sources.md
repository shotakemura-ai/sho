## 引用ルール

- 必ず URL を残す
- 引用日を記録（情報の鮮度判定）
- 公式 → wiki → ブログ の順で信頼度を割り当てる
- 矛盾する情報があれば公式優先

## 使い方の例

```
ユーザー：「魔剣士の v7.6 後期 最強構成」
1. dq10-attacker-class が呼ばれる
2. このファイル sources.md を Read
3. WebFetch で hiroba.dqx.jp の最新職調整ノートを確認
4. WebFetch で kamigami.org or wiki.dqx.jp の魔剣士ページを確認
5. 装備名・宝珠名・スキル振りを最新化して返す
```
