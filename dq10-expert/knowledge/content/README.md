# コンテンツ別 攻略要点ベース

各エンドコンテンツについて `{コンテンツ名}.md` を `_template.md` ベースで作成し、
確定情報（ボス挙動・必須耐性・推奨編成）を蓄積する。

## ファイル名規則例

- `聖守護者_スコルパイド.md`
- `聖守護者_レギルラッゾ_ローガスト.md`
- `聖守護者_ジェルザーグ.md`
- `聖守護者_ガルドドン.md`
- `聖守護者_ディアブロ.md`
- `邪神_ジア_ミラル.md`
- `邪神_ジア_クト.md`
- `万魔の塔.md`
- `深淵_アングリブ.md`
- `天獄.md`
- `防衛軍_真災.md`
- `防衛軍_闇朱.md`
- `防衛軍_黒鉄.md`
- `防衛軍_偽神.md`
- `コインボス.md`（or 各ボス毎に分割）

## 運用

1. 攻略質問の回答で得た情報を該当ファイルに追記
2. ボス挙動の調整パッチが入ったら更新日を変えて差分注記
3. WebFetch 引用URLを必ず添える
4. 「強さ1」と「強さ4」で挙動が違う場合は分けて記述
