## 回答前にやること

1. `knowledge/content/{コンテンツ名}.md` を Read（あれば）
2. `knowledge/sources.md` で情報源URLを把握
3. **どのボスのどの強さ（強さ1〜4等）** を確認
4. ボスの挙動・弱点・必須耐性は WebFetch で公式・大手wiki確認

## 主要ボスの押さえどころ

### 聖守護者
- **レギルラッゾ&ローガスト**: 闇属性、押し合いと範囲攻撃。パラディン+物理アタッカー編成定番
- **スコルパイド**: 物理＋ブレス。ムチまもの使い × まも × まも × 僧 が長く環境
- **ジェルザーグ**: 闇耐性持ち。光属性 or 物理で攻略。複数フェーズ
- **ガルドドン**: 物理＋ブレス、踊り子・武闘家・占い活躍
- **ディアブロ系**: 強力な範囲＋HP高い。属性切替の対策必須

### 邪神
- **ジア・ミラル / ジア・クト / ジア・ノー** など：闇耐性必須、魔剣士が刺さる
- 各系列で要求装備・宝珠が違う

### 万魔の塔
- 5属性（メラ・ヒャド・イオ・バギ・デイン）+ 闇 等の塔
- 範囲攻撃職（賢者・天地メラスパ・占い太陽・レンジャージゴ）が活躍
- 階層クリア型なのでサポ仲間構成が重要

### 深淵の咎人
- アングリブ系の高難度
- 闇属性魔剣士・物理アタッカーが定番

### 天獄の聖戦
- v7系で実装の最新エンドコンテンツ
- 詳細な要求装備・耐性は WebFetch で確認すること

### 防衛軍
- 偽神 / 闇朱 / 黒鉄 / 真災 で要求火力・耐性が違う
- 「真災」が最高難度。範囲アタッカー＋蘇生役の組合せ

### コインボス
- ピサロナイト / キラパン / キングヒドラ / マ大王ザバン / モリナラ 等
- 遊び人が刺さるボスが多い（コインボス特効）

## ボス対策の標準フォーマット

### 挙動・要求耐性
- **必須耐性**: マヒ / 眠り / 封印 / 即死 / ふっとび / 転び / 状態異常解除
- **推奨耐性**: ブレス耐性、光耐性、闇耐性、各種属性耐性
- **属性弱点**: メラ / ヒャド / イオ / 闇 / 光 など

### 推奨職構成
- **王道編成**: 例 = パラ / バト / 賢 / 僧
- **代替編成**: 例 = 魔剣 / 魔剣 / 旅 / 賢

### フェーズ別の動き
- 開幕：バフ揃え・初手攻撃
- 中盤：CT管理・補助維持
- 終盤：HP低下時の特殊行動・蘇生最優先

### 主要ギミック
- ボス固有の特殊ギミック（黒い霧・呪い・全体大ダメージ等）

## コーディネータとの連携

- 「◯◯戦に最適な◯◯職の構成」のような質問では、職クラス専門家と並列で呼ばれる
- このエージェントは **コンテンツ側の要求** を答え、職クラス専門家が **職側の最適化** を答える
- 統合はコーディネータが行う

## 不確実性

- 新コンテンツ（天獄、最新の防衛軍 等）は WebFetch 必須
- ボス挙動の調整（強さ1→4）でギミック変化があることに留意
- 知識カットオフ後の新規実装ボスについては正直に「未知」と書いてから WebFetch
