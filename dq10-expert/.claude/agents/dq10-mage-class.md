## 魔法使い

### コア設計
- **攻撃魔力ステ最大化型**の純魔法アタッカー
- **キー呪文**: メラゾーマ / メラガイアー / マダンテ / イオグランデ / ジバリーナ
- **キー特技**: 暴走魔法陣・零の洗礼 / 魔導の書 / 賢哲の自己暗示
- **属性弱点ボス向き**（メラ弱点＝最高火力）

### 装備の方向性
- 攻撃魔力に全振り。魔導将軍シリーズや最新両手杖
- 体上下：メラ属性ダメ＋暴走率＋呪文発動速度
- アクセ：賢哲のゆびわ、紅蓮の闘志、ファイヤーオーブ等
- ベルト：両手杖ダメ＋メラダメ

### 宝珠
- 赤：両手杖の極意 / 早詠みの杖 / メラ系呪文ダメUP / 暴走魔法陣
- 青：果てなき暴走魔法陣 / 鉄壁のドルマ系
- 黄：マヒ・眠り耐性必須（行動できないと無価値）
- 紋章：メラ系呪文強化（メラゾーマ強化、メラガイアー強化）
- 福音：呪文発動速度・攻撃魔力に振る

### スキル振り

- 詳細は `dq10-skill160-200` に委譲

### コマンド配置
- **1ページ**: メラゾーマ / メラガイアー / イオナズン / イオグランデ / 早詠みの杖 / 暴走魔法陣 / 通常攻撃 / 武器ガード / マホトラ / マホステ

## 天地雷鳴士

### コア設計
- **属性のしずく**＋**げんま召喚** が特徴。3型に分かれる
  - **カカロン型**: 補助＋回復（ハッスル＆ザオラル代わり、聖獣の翼で蘇生）
  - **メラスパーク型**: 火力（メラ属性弱点ボス）
  - **クシャラミ型**: 行動制限・攻撃力ダウン
  - **ピオラ運用型**: ピオラ4倍速で前衛支援

### 装備の方向性
- 攻撃魔力＋回復魔力＋HP
- 扇 or 棍ベース、武器ベルトは扇優先（ハッスルダンスなど）
- アクセ：神墜のゆびわ、賢哲のゆびわ
- 紋章：メラ系 / イオ系強化（型に応じて）

### 宝珠
- 赤：扇の極意 / メラスパーク強化 / 早詠みの杖
- 青：果てなき魔力かくせい
- 紋章：めいどうふうま、メラスパーク

### コマンド配置（メラスパーク型）
- **1ページ**: メラスパーク / めいどうふうま / マヒャデドス / 属性のしずく / げんま召喚（カカロン）/ 通常攻撃 / 武器ガード / ピオラ / 早詠みの杖 / 魔力かくせい
- **2ページ**: ハッスルダンス（扇のとき）/ 蘇生 / フォースブレイク

## 共通：魔法職4つの鉄則

1. **属性合わせ**: 弱点属性に構成を合わせるのが大前提（メラ弱点に氷耐性装備で行かない）
2. **発動速度**: 早詠みの杖や呪文発動速度錬金で先制を取る
3. **状態異常耐性**: マヒ・眠り・幻惑・封印は致命傷。宝珠と装備で固める
4. **補助の使い分け**: 占い師のおうえんは強力だが、火力ロスとのトレード
