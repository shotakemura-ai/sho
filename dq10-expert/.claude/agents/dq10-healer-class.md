## 僧侶

### コア設計
- **純回復のスペシャリスト**。聖守護者・邪神の最終防衛線
- **キー呪文/特技**: ベホマラー / ベホイミ / ベホマ / ザオラル / ザオリク / 聖印の守り / 天使の守り / 聖女の祈り / 心頭滅却 / 聖なる祈り
- **役割**: 蘇生最優先、HP維持、状態異常解除（キアリク・キアリー）

### 装備の方向性
- 回復魔力に全振り
- 体上下：回復魔力 + 呪文発動速度
- 武器：スティック（高回復魔力）が王道、ヤリ（前衛兼業時）、棍（範囲攻撃用）
- アクセ：神墜のゆびわ、僧侶の聖印、命のアミュレット
- ベルト：スティックダメ + 呪文発動速度

### 宝珠
- 赤：スティックの極意 / 早詠みの杖 / ベホマラー強化 / ザオラル成功率UP
- 青：果てなきベホマラー / 鉄壁の状態異常（マヒ・眠り・封印・幻惑）
- 黄：状態異常耐性、麻痺ガードは最重要
- 紋章：ベホマラー強化、ザオの巻物

### スキル振り（純回復僧侶）
- スティック / 僧侶 / シールド / 戦域 を中心
- 詳細は `dq10-skill160-200` に委譲

### コマンド配置（純回復スティック）
- **1ページ**: ベホマラー / ベホイミ / ベホマ / ザオラル / ザオリク / 聖女の祈り / 聖印の守り / 武器ガード / 通常攻撃 / 天使の守り

## 共通：回復・補助職4つの鉄則

1. **蘇生最優先**：自分が動けないと全滅。マヒ・眠り耐性は最重要
2. **HP維持**：BUF（バフ）切れに注意。聖女の祈りや旅のキラポンを切らさない
3. **タゲ取り回避**：死神ピアスや結界で被ダメ・タゲを軽減
4. **役割分担**：僧侶＝純回復、賢者＝攻め回復、デス＝集団蘇生、旅＝万能補助 を意識
