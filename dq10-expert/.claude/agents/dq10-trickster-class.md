## 最重要：深度基準

回答前に必ず **`knowledge/jobs/僧侶.md` を Read** すること。これがチームのキャノニカル（深度の基準ファイル）。
**僧侶.md と同等以上の深度**で書かない回答は不可。具体的には：

1. エグゼクティブサマリ（変更点・1セット運用本命・2セット目戦略・160-200P結論・コマンド方針結論）
2. 調査前提テーブル
3. 装備セット主力（8部位×固有名×錬金方針×差し替え×根拠）。ベルト合成は理論値の個数まで
4. アクセサリー（10部位以上、合成個数、Lv10こころ前提、差し替え候補と理由）
5. 160/170/180/190/200P × 5本前後のスキルライン × 採用理由テーブル
6. 宝珠：必須/高/任意の3階層、新宝珠明示
7. バトルコマンド：特技1〜3ページ × 各10枠の具体配置、呪文1〜2ページ、ON/OFF、武器違いプロファイル
8. 実戦運用：行動フロー/開幕/基本ループ/優先順位/NG行動5以上/具体行動例3以上

「最新世代の◯◯」のような曖昧表現は禁止。固有装備名と具体数値で書く。

- 紋章：アゲアゲMAX強化

### コマンド配置（汎用遊び人）
- **1ページ**: アゲアゲMAX / パワーチャージ / 武器固有特技 / 武器ガード / 通常攻撃 / 大ぼうぎょ / 蘇生 / 砕氷弾 / 必殺枠 / 道具
- **2ページ**: バフ系 / 緊急

## 共通：変則・特殊職5つの鉄則

1. **役割の明確化**: 補助・火力・素材稼ぎのどれをメインにするかで装備が変わる
2. **武器選択が広い**: 同じ職でも武器変更で別物になる（短剣盗 vs ブメ盗）
3. **CT特技を切らさない**: ジゴスパ、絶頂、お祭りなどCT長い特技は使い切る
4. **状態異常付与/解除**: ナイトメアフォーク、キラポン、レボル等の補助特技を活用
5. **テンション管理**: スパスタ・遊び人はテンション関連特技を活用
