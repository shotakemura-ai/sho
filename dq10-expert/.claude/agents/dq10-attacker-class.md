## バトルマスター

### 構成の型
- **両手剣型**（対大型ボス・会心特化）: 全身全霊斬り / 不死鳥天舞 / 真・やいば砕き
- **棍型**（範囲・連撃）: 一閃突き / 天下無双 / 武神の護法
- **ハンマー型**（押し合い・スタン）: スタンショット / シールドブレイク

### 装備の方向性
- 攻撃力 / 会心率 / 両手剣（または棍）スキル錬金
- 体上下：会心ダメUP / きようさ / 行動時にバイキルト系
- アクセ：剛勇のリング、忠義のメダル、武刃のゆびわ等
- ベルト：両手剣ダメ＋会心ダメ

### 宝珠
- 赤：両手剣の極意 / 棍の極意 / 会心練磨
- 青：果てなきバイキルト / 果てなき全身全霊斬り / 鉄壁のチャージタックル
- 黄：対ボスの属性耐性（呪文耐性、転び耐性、ふっとび耐性）
- 紋章宝珠：両手剣スキルダメ+、会心ダメ+

### コマンド配置（両手剣型）
- **1ページ**: 全身全霊斬り / 不死鳥天舞 / ぶんまわす / さみだれ斬り / 真・やいば砕き / 武器ガード / ミラクルブースト / 渾身斬り / 通常攻撃 / バイキルト依頼用枠
- **2ページ**: 災禍の陣（ない） / フォースブレイク / 必殺チャージ / 蘇生 / どうぐ
- **3ページ**: 緊急用・属性スキル
- **on/off**: 「ためる弐」on、「ぶんまわす」基本off（タゲ調整したいので手動）

## 武闘家

### 構成の型
- **爪型**（範囲・タップダンス）: タイガークロー / ゴールドフィンガー / 雷光烈火拳
- **棍型**（一閃突き軸）: 一閃突き / 天下無双 / 武神の護法 / 蓮華掌
- **扇型**: ハッスルダンスがあるならサポ向き。基本は前2型がメイン

### 装備の方向性
- 攻撃力・会心率・きようさ
- アクセ：黄竜のツメ、剛勇のリング、武刃のゆびわ
- ベルト：爪・棍ダメ + 会心ダメ
- 紋章：爪 / 棍スキル+

### 宝珠
- 赤：ツメの極意 / 棍の極意 / 会心練磨
- 青：果てなき天下無双 / 果てなき不撓不屈 / 鉄壁のCT短縮系
- 紋章：天下無双強化、一閃突き強化

### スキル
- 爪 / 棍 / 武闘家 / 体技 を相手に応じて
- 一閃突き連発型は棍 + 武闘家 + 体技 + 戦域系

### コマンド配置（一閃型）
- **1ページ**: 一閃突き / 天下無双 / 武神の護法 / さみだれ突き / 通常攻撃 / ミラクルブースト / 不撓不屈 / 武器ガード / もうこうだげき / ためる弐
- **2ページ**: 雷光烈火拳 / タイガークロー / ゴールドフィンガー（型に応じて） / 蓮華掌 / フォースブレイク
- **3ページ**: 蘇生 / 道具 / 緊急

## まもの使い

### 構成の型
- **ムチ型**: スコルパ・デルメゼ時代からの王道。ウォークライ＆ムチ単発
- **ツメ型**: 範囲＋会心
- **両手剣型**（v7系で再評価あり）: 不死鳥天舞型

### 装備の方向性
- HP・攻撃力・きようさ
- アクセ：忠義のメダル、武刃のゆびわ、剛勇のリング、ムチ ベルト
- 紋章：ムチスキルダメ+、ウォークライ強化

### 宝珠
- 赤：ムチの極意 / ツメの極意 / 会心練磨
- 青：果てなきウォークライ / 果てなきHP
- 黄：状態異常耐性（マヒ・封印・幻惑など相手依存）
- 緑：戦域系・行動間隔

### コマンド配置（ムチ型）
- **1ページ**: HP満タンで被ダメ系のオンガード / ウォークライ / 通常攻撃 / 鞭の特技セット / ミラクルブースト / 武器ガード / マダンテガード / 蘇生（きようなまね）
- **2ページ**: ガジェット系 / バフ / フォースブレイク

## 魔剣士

### コア設計
- **闇属性最強アタッカー**。闇耐性ダウンが入るボス（ジア・クト、深淵系）で第一候補
- **キー特技**: 暗黒連撃 / 闇の流星 / 闇のヴェール / 暗黒のヴェール / 邪炎波 / 邪気封陣
- **ダーク化**で攻撃力＆みかわし強化、HPは犠牲
- **武器**: 両手剣（火力）/ 短剣（手数・幻惑）

### 装備の方向性
- 攻撃魔力混じりの両手剣ステ＋闇属性錬金
- 体上下：会心ダメ / 闇属性ダメUP / 攻撃魔力
- アクセ：邪眼皇帝の心眼、闇のオーブ系
- ベルト：両手剣ダメ + 闇属性

### 宝珠
- 赤：両手剣の極意 / 短剣の極意 / 闇耐性減 / 闇属性ダメ+
- 青：果てなきダーク / 果てなき暗黒連撃
- 紋章：闇の流星強化、暗黒連撃強化

### コマンド配置（両手剣闇型）
- **1ページ**: 暗黒連撃 / 闇の流星 / ダークマター / 邪炎波 / ぶんまわす / 武器ガード / ミラクルブースト / 通常攻撃 / 闇のヴェール / ダーク（変身）
- **2ページ**: 邪気封陣 / 幻惑系 / フォースブレイク
- **3ページ**: 蘇生 / 緊急 / 道具

### 立ち回り
- 開幕ダーク → 邪気封陣 → 闇属性低下 → 暗黒連撃ループ
- HP管理が課題（賢者 or 旅芸人とセット）

## 海賊

### コア設計
- **両手剣 / 銃（ガン）/ サブ盾あり** の柔軟職
- **キー特技**: 砲弾ぶっぱ / アサシンアタック / トリプルショット / ファイアフォース / 暴風一閃
- **大砲**を場に置く運用が特徴

### 装備の方向性
- 攻撃力 / 会心 / 両手剣・銃スキル錬金
- アクセ：海賊の魂、忠義のメダル、武刃のゆびわ
- ベルト：両手剣 / 銃ダメ + 属性

### 宝珠
- 赤：両手剣の極意 / 銃の極意 / 会心練磨
- 青：果てなきテンション / 鉄壁の各属性耐性
- 紋章：銃スキル+、両手剣スキル+

### コマンド配置（両手剣海賊）
- **1ページ**: 暴風一閃 / 不死鳥天舞 / 全身全霊斬り / 真・やいば砕き / 武器ガード / 通常攻撃 / ミラクルブースト / 大砲設置 / アサシンアタック / 海援の旗
- **2ページ**: ファイアフォース / 砲弾系 / フォースブレイク

## 共通：物理アタッカー4つの鉄則

1. **バフ管理**：バイキルト・テンション・属性ベルトの維持
2. **会心とダメージ計算**：会心ダメUPの宝珠と装備を最大化
3. **タゲ流し**：死神ピアス / みかわし / リベホイム
4. **CT管理**：強特技（不死鳥、暗黒連撃など）はCT見ながら使い切る
