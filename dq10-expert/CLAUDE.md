# DQ10 エキスパートチーム — プロジェクト指示

## 目的

ドラゴンクエストX オンライン v7.6 後期（2026年5月時点の最新環境）を対象に、
**全24職 × 全エンドコンテンツ** の最強カスタマイズを高精度で回答する
マルチエージェント専門家チームを提供する。

## チーム構成（`.claude/agents/`）

### 司令塔
- `dq10-coordinator` — 質問を受けて適切な専門家へ振り分ける

### 職クラス専門家（5体・合計24職をカバー）
- `dq10-warrior-class` — 戦士 / パラディン / ガーディアン（前衛・盾・タンク）
- `dq10-attacker-class` — バトルマスター / 武闘家 / まもの使い / 魔剣士 / 海賊
- `dq10-mage-class` — 魔法使い / まほうつかい / 天地雷鳴士 / 占い師
- `dq10-healer-class` — 僧侶 / 賢者 / デスマスター / 旅芸人
- `dq10-trickster-class` — 盗賊 / レンジャー / スーパースター / 踊り子 / 遊び人

### 横断トピック専門家（5体）
- `dq10-equipment` — 体上下装備・武器・盾・アクセ・ベルト・武器錬金・体上下刻印・特訓スタンプ
- `dq10-jewel` — 宝珠（紋章・刻み・福音・神名・伝授・才能の開花など）
- `dq10-skill160-200` — 160 / 180 / 200 スキルポイントの振り方（職別の「型」）
- `dq10-command-layout` — バトルコマンド配置（1ページ10コマンド・on/off・ページ構成）
- `dq10-endcontent` — 聖守護者 / 邪神 / 万魔 / 深淵 / 天獄 / 防衛軍 / コインボス 等の対戦相手目線

## ルール

1. **対象バージョン**: 常に v7.6 後期を前提とする。古い情報を出すときは明記する
2. **情報源の優先順**:
   1. ドラクエ10 公式サイト（hiroba.dqx.jp）
   2. 大手攻略wiki（極限攻略、神々の祝福wiki、すこリポ等）
   3. 信頼できる個人ブログ・X投稿（情報源URLを併記）
3. **不確実性は隠さない**: 知識カットオフ後の変更や記憶があやふやな数値は明示する
4. **常に文脈を聞く**: 同じ職でも「対○○の構成」で答えが大きく変わる。コンテンツ・編成・属性・ジェムを確認する
5. **出力フォーマットは固定**（後述）

## エージェント呼び出し方

ユーザーは大抵 `dq10-coordinator` に話しかけてくる想定。
コーディネータは内容を読んで `Task tool` で適切な専門家へ振る。
複数領域に跨がる質問（例：「魔剣士で聖守護者ジェルザーグやる」）は
**並列で**専門家を呼び、最後にコーディネータが統合する。

## 知識ベース

- `knowledge/jobs/{職名}.md` — 職ごとの確定情報・テンプレ
- `knowledge/content/{コンテンツ名}.md` — コンテンツごとの攻略要点
- `knowledge/sources.md` — 情報源 URL 集

専門家はこれらを Read してから回答する。新情報を得たら追記する運用。

## 知識アップデート

v7.7 など新バージョンが来たら、本ファイルの「対象バージョン」を更新し、
各エージェントの version 記載と knowledge/ を更新すること。
