# 三幸商事 SWOT 分析 ― AI時代の鉄鋼商社として

> 作成日：2026/05/29
> 用途：経営判断・補助金申請・社内議論の起点

---

## S（強み）

| # | 内容 |
|---|---|
| S1 | **経営者自らが AI 最前線**：取締役営業部長が Claude Code で並列発注・社内ルール整備まで実装済。中小オーナーの上位 1% |
| S2 | **二本柱事業**：鉄鋼（数十億規模・安定）＋ 缶バッジ（小ロット・EC）。景気・素材市況のヘッジが効く |
| S3 | **長期取引重視の社風**：Win-Win・スポット拒否の姿勢が、AI 時代に逆に「信頼の差別化」になる |
| S4 | **Asana に社内文脈が集約**：AI が読める形でタスク・顧客情報が一元化されている（同業他社にない資産） |

## W（弱み）

| # | 内容 |
|---|---|
| W1 | **IT 投資が中途半端**：M365 + Azure を入れたが Outlook/Teams 未使用、Copilot は期待外れ。投資が回収できていない |
| W2 | **AI 活用が経営者 1 人に集中**：社内展開は未着手。属人化リスク大 |
| W3 | **家族経営的な小規模体制**：人員リソースが薄く、新規案件・DX を同時並行で進めにくい |
| W4 | **EDI 未対応**：中堅同業（中村商事等）が先行。大口顧客の発注デジタル化に取り残される懸念 |

## O（機会）

| # | 内容 |
|---|---|
| O1 | **AI 導入補助金 2026（最大 450 万円）**：M365 整理・Asana 連携深化・EDI 構築の原資にできる |
| O2 | **中小 AI 導入率 12〜20%** の今動けば、地場鉄鋼商社で「AI 先進企業」のポジション獲得可能 |
| O3 | **缶バッジ事業 × AI EC 運営**：商品ページ生成・SNS 投稿・受注対応を AI 化すれば人を増やさず売上拡大 |
| O4 | **市況据置き＋スクラップ高**：相場変動が小さい今こそ、価格交渉でなく「業務効率」で利益を出すフェーズ |

## T（脅威）

| # | 内容 |
|---|---|
| T1 | **円安 160 円防衛ライン・介入観測**：輸入鋼材・中国材コスト変動リスク。仕入れ判断の俊敏さが要る |
| T2 | **中国鋼材値上げ**：価格優位の薄板系で利幅圧縮の可能性 |
| T3 | **同業 EDI 化の進行**：未対応のままだと大口顧客から「発注しづらい商社」と見なされる |
| T4 | **カーボンニュートラル対応**：スクラップ囲い込みが進み、調達難＋環境報告義務化の二重負担 |

---

## 次の打ち手 Top3（優先順位付き）

1. **Asana × Claude の連携を本格化（補助金活用）**
   経営者の AI 力を「会社の資産」に変える最短ルート。属人化（W2）を解消し、S1・S4 を最大化。450 万円補助金の本命用途。

2. **EDI 対応の小さく速い導入**
   フル EDI ではなく、まず大口 3〜5 社向けに「メール発注 → AI 自動データ化」で代替。T3 を低コストで防ぐ。

3. **缶バッジ事業を「AI 運営の実験場」に**
   小ロット・EC の缶バッジで AI 商品ページ・SNS・受注対応を試し、成功パターンを鉄鋼の営業 DX に横展開。O3 と社内展開ノウハウを同時に獲得。
