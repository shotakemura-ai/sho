# iPhone AI 最適化ガイド — 「発注端末」化計画

> iPhone を「見る端末」から「**AI に発注する端末**」に変える。
> 目標：思いついてから発注完了まで **10秒以内**。
> 作成日：2026/07/06 ／ 24h AI 運用（`ai_operations_flow.md`）の iPhone 実装編

---

## 🎯 思想（30秒で）

| Before | After |
|--------|-------|
| iPhone = SNS・メールを見る箱 | iPhone = **24時間チームへの発注窓口** |
| Claude を開く → 打つ → 待つ | ボタン1つ or 一言で発注 → ポケットにしまう |
| 結果を見に行く | 結果が**通知で届く** |

やることは全部で **8ステップ・約30分**。1回やれば終わり。

---

## ✅ 30分セットアップチェックリスト

上から順に。各ステップ2〜5分。

### 1. Claude アプリ + 通知全許可（2分）
- App Store で Claude アプリをインストール（済みなら最新版に更新）
- 設定 → 通知 → Claude → **すべて許可**（ロック画面・バナー・サウンド）
- これが無いと「寝てる間に AI が働く」の受け取り口が無い。**最重要**

### 2. ドック配置（1分）
- ホーム画面最下段の4枠に Claude を昇格
- 候補：電話 / Safari / **Claude** / LINE（メールはホーム2ページ目へ）
- 理由：ドックは全ページ共通。「開くのに探す」をゼロにする

### 3. ホーム画面ウィジェット（3分）
- ホーム画面長押し → 「+」→ Claude
- **大サイズウィジェット**を1ページ目に：新規チャット / 音声モード / 写真解析 がワンタップ
- おすすめ優先順位：①音声モード（歩行中・運転中用）②新規チャット

### 4. ロック画面 + コントロールセンター（3分）
- ロック画面長押し → カスタマイズ → ウィジェット追加 → Claude
- コントロールセンター（右上から下スワイプ）→ 「+」→ Claude のコントロール追加
- 効果：**ロック解除ついでに発注**できる。アプリを探す動作が消える

### 5. アクションボタン（iPhone 15 Pro 以降のみ・2分）
- 設定 → アクションボタン → Claude（音声モード）を割り当て
- **長押しするだけで Claude が聞いてる状態**になる。iOS 最速の発注経路
- ※ 15 Pro 未満の機種：設定 → アクセシビリティ → タッチ → 背面タップ →「ダブルタップ」に Claude ショートカット（下記6で作成）を割り当て。これがアクションボタンの代用になる

### 6. Siri ショートカット3本（10分）

ショートカットアプリで以下を作成。Claude は App Intents 対応なので「Appを開く」より賢い動作が組める。

| ショートカット名 | 中身 | 起動方法 |
|------------------|------|----------|
| **いつものお願い** | Claude で新規チャット → テキスト「いつものお願い。」を送信 | 「Hey Siri いつものお願い」/ 背面タップ |
| **朝パック** | Claude で新規チャット → 「B-001。出力はいつもの場所。終わったら ops_log に記録して。」 | 「Hey Siri 朝パック」/ ウィジェット |
| **夜パック** | Claude で新規チャット → 「B-002。出力はいつもの場所。終わったら ops_log に記録して。」 | 「Hey Siri 夜パック」/ ウィジェット |

作り方（3本とも同じ手順）：
1. ショートカットアプリ → 「+」
2. アクション検索で「Claude」→ 「新しい会話を開始」（または「Ask Claude」）
3. プロンプト欄に上記の定型文を入れる
4. 名前を付けて保存 → ホーム画面 or 背面タップに割り当て

→ これで**布団の中から声だけで B-001 が走る**。

### 7. 音声入力の日本語最適化（3分）
- 設定 → 一般 → キーボード → **音声入力 ON**（日本語）
- Claude の音声モードは日本語対応済み（2026/06〜多言語対応）。長い発注は音声モード、短い発注は Siri ショートカット、と使い分け
- コツ：発注は「T-205 を今やって」「B-002」のように**コード名で言う**と誤認識ゼロ

### 8. claude.ai/code をホーム画面に追加（2分）
- Safari で claude.ai/code を開く → 共有 → **ホーム画面に追加**
- アプリ＝会話・音声発注用、code＝**並列セッション管理・Routines 確認用**と役割分担
- 置き場所：ホーム1ページ目、Claude アプリの隣

## 🗺️ 発注動線マップ（シチュエーション別・最速経路)

| いつ | 状況 | 最速経路 | 所要 |
|------|------|----------|------|
| 05:30 布団の中 | 通知で朝ブリーフ確認 | ロック画面通知タップ → 読むだけ | 0秒発注（L3 が勝手に動いてる） |
| 07:00 通勤（歩き） | 追加発注したい | アクションボタン長押し → 声で「T-202 やって」 | 5秒 |
| 07:30 電車内 | まとめ発注 | 「Hey Siri 朝パック」or ウィジェット | 3秒 |
| 日中 移動・会議の合間 | 思いつきメモ的発注 | コントロールセンター → Claude → 一言 | 10秒 |
| 21:00 寝る前 | 並列大量発注 | 「Hey Siri 夜パック」→ 追加があれば code で新規セッション | 1〜3分 |
| 車の運転中 | ハンズフリー | アクションボタン長押し → 音声モードで会話 | 手を使わない |

**原則：発注したらポケットにしまう。** クラウドセッションはアプリを閉じても動き続ける。結果は通知が教えてくれる。

## 🔕 通知が多すぎる問題への予防線

全許可にすると通知が増える。溺れないためのルール：

1. **即読むのは B/C レベルだけ**（`ai_operations_flow.md` の結果ハンドリング参照）。A レベル（ニュース要約等）は朝コーヒー10分でまとめ読み
2. 会議中は**集中モード**（仕事）で Claude 通知だけ許可、他アプリは遮断 — 逆転の発想。AI の完了報告は仕事情報なので通す
3. 週次振り返り（R-weekly-review）で「読まなかった通知」があれば、その発注自体を見直す

## 📌 現在地とこのガイドの位置づけ

```
L1 手動発注     ← このガイドで「10秒発注」に高速化 ★今ここ
L2 バンドル発注  ← ショートカット「朝パック」「夜パック」で1タップ化 ★今ここ
L3 完全自動     ← Routines（登録済みなら iPhone は受信専用端末）
```

iPhone 最適化のゴールは「頑張って発注する」ではなく、
**発注が呼吸レベルで無意識になり、L3 の検収だけが残る**こと。
