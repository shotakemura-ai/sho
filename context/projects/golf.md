### 基本の考え方
- ゴルフは誰でも上手くなれる
- 基本はあるがプロでもフォームはそれぞれ違う
- **ゴルフは本来右脳（感覚）でやるもの。** YouTubeの影響で左脳（理論）になり難しく考えすぎている人が多い

### クラブの基本
| 種類 | 特徴 |
|------|------|
| ドライバー | 唯一地面から打たないクラブ |
| ウッド / ユーティリティ | アイアンと同じ打ち方 |
| アイアン | 距離感を打つクラブ |
| ウェッジ | アプローチ用。アイアンとは打ち方が違う |

- ドライバーからサンドウェッジの中間は6I
- 9Iの飛距離の2倍 ≒ ドライバーの飛距離

### 今日の指導内容

**① グリップとアドレスが最優先（PGAの基本）**
- 右に行くグリップ・アドレスなのに「右に行く」と悩む、左も同様 → グリップ・アドレスが原因なのに気づいていない人が多い
- まっすぐ打てる人は3割。左か右に行く人が7割
- まず自分の球筋（左 or 右）に合ったグリップ・アドレスを作ることが先

**② 円運動の意識**
- スイングは円運動。フラフープを持って円を描く練習
- 顎から大きい円と小さい円 → この範囲から外れなければ当たる
- **喉仏から手までの距離が変わらなければ必ず当たる**

**③ ボール位置**
- グリップ・アドレスができたら、自分が一番上手く打てるボール位置を見つける
- スイングプレーンや軌道はプロでも外れている人がたくさんいる → 気にしすぎない

**④ 体の使い方**
- 「体が硬い」は関係ない
- 若い人 → 捻る（パワー）
- 年配の人 → 動かす（ミート率は下がる）
- 手が重要。クラブをいかに動かすかは手で決まる
