1. **喉仏〜グリップの距離を変えない** — これさえ守れば必ず当たる
2. **重心を管理する** — 胸の前に吊るした5円玉が動かないイメージ。足の裏で体重を感じる
3. **シャフトの傾きを維持する** — 8Iなら47度。立てて下ろさない、寝かせたまま
4. **リズムは全部一緒** — 上げる・下ろす・当たった後、同じスピード。当たる瞬間に速くしない
5. **インサイドから下ろす** — アウトサイドインは絶対NG。上げた軌道と同じところを下ろす
6. **左手でしっかり持ち、右手は添える** — 力は入れてよい。「力を抜け」はプロ用の言葉
7. **考えるのは手とクラブだけ** — 腰や体の回し方は考えない。手がクラブをコントロールする
8. **円の底辺を長く** — クラブが地面の低い位置を通る時間を長く。力ではなく効率とミート率で飛ばす
9. **動かしすぎない** — 「これぐらいでいい」に落とす。飛ばしたい力感が当たりをバラつかせる
10. **下半身がきっかけ** — バックスイングは右かかと、ダウンは左足かかと・膝が先。手はその結果ついてくる
11. **腕は振らない、手首を使う** — 手首の角度（コック）がスピードの根源。「手打ちはダメ」に惑わされない
12. **右手は支点、左手が力点** — 右手は何もしない（支えるだけ）。左手で引っ張ればアウトサイドインは出ない
13. **近道をしない** — 最短でボールに当てたい衝動がアウトイン・力みの正体。遠回りをゆっくり来る
14. **迷ったらボウリング** — トップからボウリングの球を投げ下ろすイメージ。軌道が勝手に整う
15. **バックスイングの位置が全ての前提** — トップがズレていたら、どう下ろしてもアジャストが必要になる
16. **アプローチは上げない・転がす** — 8I転がしが最安全。Sでふわっとは最リスク。高さの引き出しを知って一番安全な絵を選ぶ
17. **ヘッドは顔の横を通さない** — ダウンでヘッドは右肩・右腕の横より低い位置を通る。顔の横=力み・アウトの証拠

## 第2回 — 2026年5月18日（日）「重心とスイングプレーン」

### 指導内容

**重心の理解**
- 前傾姿勢では**重心は体の外（お腹の前の空間）にある**
- だから足の裏で体重を感じることが重要。親指が浮くと後ろに崩れる
- 「足腰が大事」の正体はこの重心管理

**スイングプレーン**
- 構えたシャフトの斜めを維持したまま回す → 「面」ができる
- この面の上をクラブが動けば当たって飛ぶ
- 9Iは急角度、ドライバーはフラット。クラブごとにプレーンが違う
- **体の動き（肩・腰）は結果であって目的ではない**

**映像解析での発見**
- 正面: 軸はまっすぐ ✅
- 側面: バックスイングで頭が下に落ちる ❌ / クラブがプレーンの外に上がる ❌ / アウトサイドイン軌道 ❌
- 今のスイングは原理上当たるが「**距離が出ない**」のが最大の損

**プロの実例**
- 完璧なオンプレーンの教え子（高校生）もいれば、プレーンから外れたまま年間5,000万稼ぐプロ（西村優奈）もいる
- 目指すのはオンプレーン。ただし完璧でなくてもやれることは多い

### 処方箋
- 頭が下がる → **目とボールの距離を変えない**
- 右手が強い → 減らすか活かすか、やりやすい方を選ぶ。最終的に**左右両方をうまく使う**

## 第3回 — 2026年5月25日（日）「重心管理の実践と軌道修正」

### バランスディスク × 重い棒の練習
- 空気入りディスクの上で重い鉄棒を振る → グラつく中でバランスが取れた位置 = **自分の重心の安定位置**
- ゴルフの構え = ジャンプして着地した形（股関節・膝・足首が曲がる）
- 重心の正解位置は人それぞれ。ディスクの上で立てていればそこが正解

**結果: 重心を意識しただけで、クラブが勝手にプレーン上に上がるようになった。頭も動かなくなった。**

### 頭を動かすなの本当の意味
- 頭は4〜5kg。この重量物が動く = 重心がズレる
- 逆に、あえて頭を上下に動かして飛ばすドラコン選手もいる（当たり外れは大きい）

### アウトサイドインの修正
- 自分では「まっすぐ下ろしている」つもり → 実際は外(前)から入っていた
- **上げた軌道と同じところを下ろすだけでいい。**行きと帰りが違うから不安定になる
- 教え子は全員インサイドから下ろす（中1女子は2年でスコア70台）

### 弓を引くイメージ（ダウンスイング）
- トップから**弓を引いて離す感覚**。プレーンの斜め後方にエネルギーを溜める
- 左肘は伸ばしたまま・手首固定で、引っ張り合いに耐える
- 地面と平行のあたりで解き放つ → クラブが**体に巻きつくように**回り込む
- この動きなら頭も重心もズレない

### シャフト47度の維持
- 8Iのシャフト角は約47度。**この傾きを保ったまま振れば元の位置に戻り、まっすぐ飛ぶ**
- 自分はシャフトを立てて下ろすクセがあった → 寝かせたまま下ろす
- クラブが長いほどフラットになるが、「傾きに沿って振る」原則は全クラブ共通

### リズムの教え
- 当たる瞬間に加速しない。**上げ・下ろし・フォローを同速で**
- まずゆっくり振ってクラブの居場所とフェース向きを知る → プロは全員これが分かって振っている

### ゴルフ談義（記録として）
- ゴルフは球技で一番飛ばせる。だからドライバーに魅了される。飛ばせるうちは飛ばすべき
- アプローチの方が実は難しい（スピン・高低・曲げの引き出しが必要）。スコアに直結
- 同じ完璧なスイングでも本人の感覚表現は全員違う。**だからネット情報は矛盾して見える**
- テニス・卓球は腕の延長線上に面がある。ゴルフはシャフトからずれた位置に面がある＋勝手に回る → だから難しい。**難しいから面白い**
- 球筋がスライス → **軽いドロー系に変わってきた。**軽いドローが一番飛ぶ弾道

## 第4回 — 2026年7月上旬「ミート率と体の回し方・ドライバー矯正」

※前回から間が空いた回。7/25奈良国際まで残り2週間の逆算レッスン

### クラブ診断
- 自分の「ちゃんと当たるボーダー」は**7番アイアン**（6Iは当たる確率がガクッと落ちる）
- FWはロングのセカンド・200yd超で使うが当たっていない
- コーチの方針: **7I・8Iが当たれば長物は「同じ動作でただ長いだけ」**。短めに持てば代用できる

### 力感と距離の一致
- 出力（力感）とボールの飛びが比例してくると、リズムと体重移動が自然に取れてくる
- 今は**力感と距離が合っていない = 損している**
- 「力を入れていないのに飛ぶ」効率のいいポイントを明確にしていくのがスイング作り

### ミート率の根源
- 直径4.2cmのボールを斜めの面で打つのは本来難しい。ダフリ・トップは構造上出るもの
- **10回打って10回同じ当たりにする**のが目標。その根源は「肩・首・頭・腰」
- 肩が回る＝首がねじれる。バックスイングで頭がずれる＝軸がずれる＝当たりがまばら
- 自分は腕を上げると同時に頭がずれる癖がまだある
- **動きを入れすぎ。「典型的な日本人、働きすぎ」**。動きを減らすと飛ばない気がするのは錯覚

### かかと抜重ドリル（今日の核心）
バランスディスク＋フラフープで体の回し方を体得：
1. 左肘を伸ばし、**腕と胸の距離（テンション）を変えないまま**限界まで回る
2. 限界が来たら**右足かかとに体重を乗せる（抜重）→ 右腰が回る → 右肩が回る**
3. アドレス時の左腕の距離を一切変えない。これがスイングの絶対条件
4. ダウンは逆再生。左足かかと→左腰→左肩の順で、前に出た左サイドを元の位置に戻す
5. 円は地面に対して**斜め**。中心を維持したまま斜めの円を描く

→ **これがハーフスイング。この範囲で動かせれば必ずボールの芯とクラブの芯が当たる**
→ バックスイングよりダウンで左足に少しずれるのはOK（エネルギーがかかるため）

### 自分の癖の指摘
- **アーリーエクステンション**（腰が前に出て伸び上がる）が出る → 膝・腰の位置キープを意識
- 頭を正面に向けたままにすると「ずれてない意識」が保ちやすい
- メガネのフレームからボールを外したくない心理で逆に回れなくなる人が多い（自分も該当）

### ドライバーの矯正
- **テンプラ傷を指摘される** → 原因は打ち込み型セットアップ
- 修正点:
  - **ボール位置は左脇の前に固定**（体の幅の中で左サイド）。毎回絶対同じ位置
  - 頭は足と足の真ん中
  - 構えは**大文字のY**（今までは小文字のy＝ハンドファースト過ぎ）
  - **フェースの銀色が見えるくらい**上向きにセット。球が上がらないと飛ばない
- ドライバーは大きく動かす必要なし。円周が長い分**ラグ（遅れ）が来るのでお腹に力を入れて待つ**

### スコア戦略（コーチの結論）
- **スコアを作るのは80〜100ヤード以内。**ピッチング以下を猛練習すればスコアは余裕で切れる
- ドライバーは自己満足。1ラウンド14回のうち4〜5回いい球が出れば十分
- ドライバーがミスってもセカンド以降で80yd以内に運び、そこでパチンと当たればボギーで上がれる

### ジャスティン・トーマスの15cm
- PGAのデータ計測で、インパクト時にクラブが**地面に15cm接地**している
- ボールの「前」の芝が取れるのがプロ。アマチュアは後ろを削る（ダフリ＝ボールとの間に芝と土が入る）
- **円の底辺を長くすれば、同じスピード・同じ振り幅でも距離が伸びる** ← 実演で証明された

- 8Iの小さい転がしでも実はボール1〜3個分は上がっている（17〜20yd先まで届く）→ 手前の障害も意外と越えられる

### バウンス角の知識
- ソールの出っ張り角。ローバウンス8度／ハイバウンス14度
- ハイバウンス: 地面に先に当たって跳ねやすいが、良いライやサラサラの砂では滑ってミスを軽減
- この辺のコースは砂が粗く硬い → コーチはローバウンス派
- **バンカー＝S固定の思い込みを捨てる。**顎から遠ければP/Aの方が少ない力で越えて飛ばせる。顎の近さと高さで使い分ける

### アプローチの打ち方（技術の核心）
1. **左肘・左手首をだらーんと伸ばした状態で握り、バックスイングで関節を一切動かさない**（手首の動きを極力抑える。パッティングも同じ）
2. **左膝を軽く曲げる** → 左腰・左肩が自然に下がる → その形をキープ。頭は左足の上くらいの感覚
3. **ソールでマットを「歯ブラシのブラッシング」くらい軽く触る。**触らない＝浮いている＝トップ気味の証拠
4. 支点は手首ではなく**肩と肩の真ん中あたり**
5. 振り子は重力だけのスピードが基本。そこに力を足すから変化（ミス）が生まれる
6. **素振りは本番と同じスピードで。**素振りゆっくり→本番だけ速いのが自分の癖だった

### ドライバー再確認
- 力むとダウンでクラブが**顔の横**を通る（フェース上部の汚れ＝テンプラ跡がその証拠）
- 正しくは**ヘッドが右肩・右腕の横より低い位置**を通って下りてくる
- 「ヘッドは顔の横を通さない」の一言でナイスショット連発。ドライバーはこれ絶対

### メンタル講話（9/3に効く）
- 飛ばし屋と回ると力んで自滅するのが定番。**体格差は勝てないと割り切り、自分のゴルフをする**
- 接待の本質は「時間の短縮＝迷惑をかけないこと」。ただし焦って早く打つのはマナーではない
- ティーショットがダメでも「すいません」と言いながら**短いのでスコアを作る**
- 「ちゃんと練習してきてるんだな」が見えるのが一番いい。知ってる人は「随分変わったね」と絶対言ってくれる
