### 基本の考え方
- ゴルフは誰でも上手くなれる
- 基本はあるがプロでもフォームはそれぞれ違う
- **ゴルフは本来右脳（感覚）でやるもの。** YouTubeの影響で左脳（理論）になり難しく考えすぎている人が多い
- YouTubeは物理寄りの解説が多く複雑になりすぎている。もっともらしく聞こえるのでみんな参考にしてしまうが、うまくいかない

### クラブの基本
| 種類 | 特徴 |
|------|------|
| ドライバー | 唯一地面から打たないクラブ |
| ウッド / ユーティリティ | アイアンと同じ打ち方 |
| アイアン | 距離感を打つクラブ |
| ウェッジ | アプローチ用。アイアンとは打ち方が違う |

- ドライバーからサンドウェッジの中間は6I
- 9Iの飛距離の2倍 ≒ ドライバーの飛距離

### 今日の指導内容

**① グリップとアドレスが最優先（PGAの基本）**
- 右に行くグリップ・アドレスなのに「右に行く」と悩む、左も同様 → グリップ・アドレスが原因なのに気づいていない人が多い
- まっすぐ打てる人は3割。左か右に行く人が7割
- まず自分の球筋（左 or 右）に合ったグリップ・アドレスを作ることが先

**② 円運動の意識**
- スイングは円運動。フラフープを持って円を描く練習
- 顎から大きい円と小さい円 → この範囲から外れなければ当たる
- **喉仏から手までの距離が変わらなければ必ず当たる**

**③ ボール位置**
- グリップ・アドレスができたら、自分が一番上手く打てるボール位置を見つける
- スイングプレーンや軌道はプロでも外れている人がたくさんいる → 気にしすぎない

**④ 体の使い方**
- 「体が硬い」は関係ない
- 若い人 → 捻る（パワー）
- 年配の人 → 動かす（ミート率は下がる）
- 手が重要。クラブをいかに動かすかは手で決まる

**⑤ 意識すること**
- 頭の中では「喉仏〜グリップの距離を変えない」とだけ考える
- 腰を回すとか体をこう動かすとかは考えない。**手がクラブをコントロールしている**のだから手だけ意識する

**⑥ グリップの力（重要）**
- 「力を抜いて」「ひよこを持つように」は**真っ赤なウソ**
- **力は入れる。**握る
- プロが「力を抜け」と言うのは、力を入れると疲れて何ラウンドもできないから。体力温存のために抜くだけ
- アマチュアが1ラウンドなら力を入れて問題ない
- プロが「力を抜く」のは、力を入れなくても喉仏〜グリップの距離を一定に保ったまま振れる感覚を掴んだから。**それまではやはり力を入れるのが正解**
- **左手でしっかり持ち、右手は添える**

**⑦ 生涯スポーツとしてのゴルフ**
- ゴルフは生涯スポーツ。10年ごとくらいに少しずつスイングを変えていく
- 年齢とともに可動域・筋力は落ちる → スイングを小さくする提案をすると「飛ばなくなる」と言われる → 「ならストレッチと筋トレしましょう」と言うと「この年でそんなことできない」と言われる
- **相応の妥協をしても十分楽しめる。**それがゴルフ
- 野球をやってる人が全員大谷のフィジカルを持っているわけではないし、タイガー・ウッズのフィジカルを持っているわけでもない

**⑧ マンツーマンレッスンの意義**
- 年齢・性別・体格・骨格・性格、全て違う → 1人1人に最適な指導が違うのは当たり前
- **柔軟性も人それぞれ違う**
- イチローだって超個性的なフォームを突き詰めてあそこまでいった。どのスポーツでも同じ、ゴルフでも同じ
- **だから集団レッスンは無理がある**

### 自分の課題
- **体が動いてしまっている** → 動かないようにする
- **喉仏とグリップの距離を一定に保って振る**練習
- 現状は自然と**スライスグリップ**になっている → 修正が必要

### 次回までの練習
- 喉仏〜手の距離を一定にしてスイングする素振り
- グリップの見直し（スライスグリップからの矯正）

### 今日の指導内容

**① 重心の理解**
- ゴルフの構えでは**重心は空間（お腹の前）にある**（体の内部ではない）
- まっすぐ立った時は体の内部に重心がある。前傾すると体の外（前方）に移動する
- だから**足の裏で自分の体重を感じる**ことが重要
- 足の親指が浮いたら後ろに下がる＝バランス崩壊
- 足腰が大事と言われるのはこの重心管理のため
- 体操で平均台ができる子は、この重心感覚が優れている

**② スイングプレーン（面）の概念**
- クラブは斜めに構える → その斜めを維持したまま回すと「面」ができる
- この面の上をクラブが動けば、ボールに正しく当たり飛ぶ
- **9Iは急な角度、ドライバーはフラットな角度** → クラブごとにプレーンが違う
- プレーン上を動かすことが最優先。体の動き（肩・腰）はその結果であって目的ではない

**③ 現状のスイング分析（映像解析）**
- 正面から見ると軸はまっすぐ → アドレスのバランスは良い
- 問題①: バックスイングで**頭が下に落ちる**（前傾が深くなる）
- 問題②: クラブが**プレーンより外（前方）に上がっている**
- 問題③: ダウンスイングで**アウトサイドイン軌道**（スライスの典型）
- 今のスイングは「まっすぐ上げてまっすぐ下ろす」＝原理的には当たるが、**距離が出ない**のが最大のデメリット

**④ プロとの比較**
- 見本: コーチが小学生から指導してきた高校生。クラブが完全にプレーン上を動く（オンプレーン）
- プロでもプレーンから外れる人はたくさんいる。が、構えた位置に近い再現性を持っている
- 西村優奈プロ: プレーンから外れているが年間5,000万稼いでいる
- **目指すのはオンプレーンだが、できなくてもやれることはたくさんある**

**⑤ 修正の方向性**
- クラブが外に上がる → **プレーンの2本ライン内に収める**
- 頭が下がる → **目とボールの距離を変えない**意識で防げる
- 右手が強すぎる（パチンと叩きにいく） → 右手を減らすか、活かしてプレーン上を動かすか、やりやすい方を選択
- 右手も左手も**両方うまくスイッチして使う**必要がある

**⑥ 骨格と可動域**
- 体には動かしやすい方向と動かしにくい方向がある（肘関節と同じ原理）
- クラブをプレーン上に上げようとすると、自然と体が大きく動く場合がある
- 無理な方向に動かそうとすると補正動作が入り、別の問題が生まれる
- 各自の骨格に合った動かし方を見つけることが大事

**⑦ 心理面**
- スイングには心理的な部分も入ってくる
- 技術だけでなくメンタルの理解も必要

### 自分の課題（更新）

## 2026年5月25日（日）第3回

### 今日のテーマ：重心管理とクラブの動かし方の根本

**① ゴルフの魅力**
- ゴルフは球技の中で**一番ボールを飛ばせる球技**。だからドライバーは魅了される
- アプローチはドライバーより難しい。多種多様なスイングが必要（スピンあり/なし、高い/低い、フック/スライス回転、バックスピン等）
- ドライバーは飛ばせるうちは飛ばした方がいい

**② バランスディスクを使った重心トレーニング**
- 空気入りのバランスディスクの上に乗り、重い鉄の棒を振る練習
- グラグラする中でバランスを取れた位置＝**重心が安定している位置**
- ゴルフの構えは「ジャンプして着地した時の形」に近い。股関節・膝・足首が曲がった状態
- **重心の位置は人それぞれ違う**。骨格・体格・可動域が違うから。答えは出ていない
- バランスディスクの上で立てていれば、それが自分のバランスの取れた位置

**③ 重心の再確認（第2回の深掘り）**
- 胸の真ん中あたりに紐で吊るされた5円玉があるイメージ → その位置が重心
- その5円玉が前後左右に動かないようにクラブを動かす
- 頭は成人男性で4〜5kg。前傾姿勢でこの重さが体の前にあるから肩がこる
- **頭を動かすな＝こんな重いものが動くと重心がずれるから**という意味

**④ 重い棒で振った後のスイング変化（映像比較）**
- 前回（重心意識なし）: クラブがプレーンの枠から大きく外れていた
- 今回（バランスディスク後）: 枠からの外れが大幅に減少
- **重心管理を意識しただけで、構えた体勢を変えないまま勝手にプレーン上に上がるようになった**
- 頭もほとんど動かなくなった

**⑤ アウトサイドインの原因と修正**
- 自分のスイングは「まっすぐ下ろしている」つもりだが、実際は後ろから前に来ている（アウトサイドイン）
- **アウトサイドインは絶対やらない方がいい**（あえてスライスを打つ場合以外）
- 上げた位置と同じところを下ろせばいい。行き帰りの軌道が違いすぎると不安定になる
- コーチの教え子（中1女子、2年でスコア70台）もプロも全員**インサイドから下ろしている**

**⑥ 弓を引くイメージ（ダウンスイングの感覚）**
- トップの位置からダウンスイングは**弓を引いて離す感覚**
- プレーンの斜め方向にエネルギーを溜める → 地面と平行になったあたりで解き放つ
- 左肘は伸ばしたまま、手首も固定。その状態でプレーン方向に引っ張り返す
- 解き放たれたクラブが**体に巻きつくように回り込んでいく**
- この動きなら頭の位置も重心もずれない

**⑦ シャフトの傾き（47度）を維持する**
- 8番アイアンならシャフトの傾きは約47度
- この47度をずっと維持したまま振る → クラブが元の位置に戻る → まっすぐ飛ぶ
- 自分の場合、シャフトを立てて下ろしていた → **寝かせて下ろさないと当たらない**
- クラブが長くなるほど傾きはフラットになる。この傾きに沿って振るのは全クラブ共通

**⑧ スイングのリズム**
- 当たる瞬間に速くしない。**上げるスピード＝下ろすスピード＝当たった後のスピード、全部一緒**
- 速く当てようとする＝ボールをめがけて何かしようとする動き → 軌道が崩れる
- まずゆっくり振って、クラブがどこをどう動いているか知る → そこから速くしても分かるようになる

**⑨ プロの感覚は人それぞれ**
- 同じ完璧なスイングをしている人でも、本人の感覚・言葉の表現は全然違う
- 右利きと左利きでも違う。だから**ネットの情報は逆のことを言ってるように見える**
- コーチの立場: クラブを扱う物理的な部分 + 体の運動の常識的な部分、この2つを教える

**⑩ ゴルフの深さ**
- 22〜23年通っている生徒もいる。上手くなるほど深くなる
- シングル（ハンディ9以下）になっても悩み続ける。プロでもオリンピック金メダリストでも悩む
- 面を扱うスポーツ（テニス・卓球）は延長線上に面がある。ゴルフはシャフトからずれた位置に面がある＋勝手に回る → だから難しい
- **難しいから面白い。**理系の人は物理が入るから特に楽しめる

### 自分の課題（更新）
- ~~頭が下がる~~ → 重心管理の意識で改善
- ~~クラブが外に上がる~~ → バランスディスク後に大幅改善
- **アウトサイドインをインサイドからに変える** → 上げた軌道と同じところを下ろす
- **シャフトの傾き（47度）を維持して振る** → 立てて下ろさない
- **スイングのリズムを一定にする** → 当たる瞬間に速くしない
- 弓を引いて離す感覚でダウンスイング

### 次回までの練習
1. **バランスディスク練習**（あれば）— 重心の安定位置を体で覚える
2. **ゆっくり一定リズムで素振り** — 上げ・下ろし・フォローを同じスピードで
3. **シャフトの傾きを意識** — 寝かせたまま下ろす感覚
4. クラブが空間をどう動いているか、フェースがどこを向いているか感じながら振る
