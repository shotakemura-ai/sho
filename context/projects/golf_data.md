# TrackMan Range 練習データ — 竹村翔

## 📐 TrackMan練習の型（毎回これでやる）

### 原則
1. **1球1目的。**目的のない球は1球も打たない（コーチの「数より質」と同じ）
2. **見る数値は2つだけ: キャリーと左右のブレ。**ボールスピード・打ち出し角などの物理数値は見ない（左脳化するとスイングが崩れる — コーチのYouTube警告と同じ理屈）
3. **打つ前に宣言してから打つ。**「9Iで90y、あのターゲット」→打つ→数字で答え合わせ。この往復が上達の最小単位
4. 60分50〜60球まで。疲れた球はデータを汚すだけ

### モードの使い分け
| モード | 用途 | 頻度 |
|--------|------|------|
| **練習（ターゲット指定）** | 距離の答え合わせ。宣言→実測のズレを縮める | 毎回のメイン |
| **マップマイバッグ** | クラブ別データの定点観測 | **月1回だけ**（毎回やると練習にならない） |
| **競技（ニアピン等）** | プレッシャーの疑似体験。1球の重みを作る | 毎回最後の10分 |

### 毎回の60分テンプレ
| 配分 | 内容 |
|------|------|
| 15分 | **レッスン課題ドリル**（今の課題1つだけ。数字は見ない） |
| 25分 | **ターゲット練習**: エースクラブ（9I・6I）で距離宣言→答え合わせ。±10y以内なら合格 |
| 10分 | **弱点1本だけ再計測**（今なら8I or 5UT を5球。直すのではなく現状把握） |
| 10分 | **バーチャルラウンド or 競技モード**: 毎球クラブを替え、3秒ルーティンで |

### 追跡するKPI（月次で推移を見る）
- 9Iのキャリー±10y以内率（現在: 6球中5球 ≒ 83%）
- 6Iのばらつき幅（現在: 16y）
- 8Iのばらつき幅（現在: 44y ← 最優先の改善対象）
- ドライバーの左右ブレ幅

### データループ
練習終了 → セッションのスクショをClaudeへ → golf_data.mdに追記 → 月1でレッスン記録（golf.md）と突き合わせて推移レポート

### 数値分析

**発見①: 8Iの逆転現象**
- 8Iの平均キャリー（86y）が**9I（94y）より飛んでいない**

**発見②: ミドルアイアンのギャップ圧縮**
- 芯を食った時のキャリー: 7I≒105y、8I≒100y、9I≒98y → **3本で7yしか違わない**

- ミート率が上がれば自然にギャップが開く（レッスンの方向性と一致）。今は気にしない

**発見③: 9Iが最も信頼できる**
- ばらつき幅20yで最小。82y以下のミスがない

**発見④: SW→PWの間に17yの空白**
- SW68y／PW85y。この間（70〜80y）はAW（アプローチウェッジ）の距離

### 🧭 実戦のクラブ選択ルール（ピンまで／エッジまでの2距離で決める）

**手順: ①ピンまでの距離からそのクラブのランを引く＝狙うキャリー ②そのキャリーがエッジとの関係でどこに落ちるか確認**

**エッジとの関係で上書きするルール:**
1. **手前ピン（エッジ〜ピンが10y以内）** → ランの多い6I/7I/5Wで直接狙わない。SWか9Iで止めにいくか、割り切って2段構え
2. **キャリーがエッジ手前に落ちる×花道** → むしろ理想（転がり上がる）。6I/7Iの出番
3. **ガードバンカー越え** → キャリーがエッジを越える番手が絶対条件。PWの「薄い」が出ると大惨事なので、バンカー越えは9IかSWの距離まで刻んでから
4. **奥ピン** → 全クラブ安全。トータル基準でそのまま打つ
