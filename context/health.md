> 2026年4月27日 作成

|------|------|

## フェーズ1「慣らし」（4/27〜5/11）

変えるのは3つだけ。量は減らさない。

| 行動 | 具体 | タイミング |
|------|------|-----------|
| 水を飲む | 500mlペット×3本（1.5L/日） | 朝起床・昼食時・夕方 |
| 酒を置き換え | ビールやめ→ハイボールのみに | 毎晩 |
| 10分歩く | 昼食後に10分だけ（それ以上やらない） | 昼休み |

## フェーズ2「休肝日導入」（5/12〜6/8、クリニック受診後）

| 行動 | 具体 |
|------|------|
| 週2日休肝日 | 月曜・木曜（金曜は会食多いので避ける） |
| 休肝日の代替 | 炭酸水＋レモンを冷蔵庫に常備 |
| 歩く距離UP | 10分→20分 |
| 朝に何か摂る | プロテインかヨーグルト1つ |

## フェーズ3「定着」（6/9〜）

| 行動 | 具体 |
|------|------|
| 酒の量を減らす | ハイボール350ml×2→1本 |
| 休肝日を週3に | 月・水・木 |
| 歩く30分 | 通勤経路を1駅分歩く等 |

## 昼食ガイド（外食）

### OK（週の半分以上をこちらで）
- 定食屋: **焼き魚定食**、**生姜焼き定食**（ご飯少なめ）
- カレー: **野菜カレー**（カツカレー避ける）
- 中華: **回鍋肉定食**、**レバニラ以外の野菜炒め**
- コンビニ: **サラダチキン＋おにぎり1個＋サラダ**
- そば・うどん: **ざるそば＋小盛りご飯**

### 控えめに（週1-2回まで）
- ラーメン（スープ残す。替え玉しない）
- とんかつ（ロースよりヒレ。ご飯少なめ）
- カツカレー
- 天丼・かつ丼

### NG（尿酸値に直撃）
- レバー・ホルモン系
- 白子
- 干物（アジの開き等）
- 魚卵（明太子・いくら）の大量摂取

## 飲酒ガイド

### プリン体が少ない（OK）
- **ハイボール**（ウイスキー系）
- **焼酎ソーダ割り**
- **ワイン**（グラス1-2杯）

### プリン体が多い（避ける）
- **ビール**（最もプリン体が多い）
- **発泡酒**
- **日本酒**（やや多い）

### 会食時のルール
- 1杯目からハイボールでOK（「ビール飲めないんですよ」で十分）
- 水を交互に頼む（酔いにくい＋水分摂取）
- 2軒目は断る
