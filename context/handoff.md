# 引き継ぎメモ（Codex ⇄ Claude／端末をまたぐ「ここまでやった」）

> Claude 以外（Codex の代打・別端末）で作業したときに、**やった側が3行で書く**。
> Claude はセッション開始時にここを読み、未検品の行があれば「引き継ぎ N件あり」と1行報告して検品する。
> 検品が終わった行は Claude が `[検品済 YYYY-MM-DD]` を付ける（消さない。R-weekly が月1で古い行を掃除）。

## 書き方（やった側）
```
### YYYY-MM-DD HH:MM  by Codex（or Mac / 会社PC）
- やったこと：（1行）
- 成果物：（パス。複数なら列挙）
- 未完・要確認：（無ければ「なし」）
```
