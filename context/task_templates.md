# タスクテンプレート集

> Claude Code を並列で動かすための「定型タスク辞書」。
> 寝る前に「これとこれとこれ、お願い」と一言で投げられるように、頻出タスクを定型化している。
> 各テンプレは独立して実行できる（並列起動を想定）。

---

## 使い方の基本ルール

### 並列実行の鉄則
1. **1セッション = 1タスク**。複数を1セッションに詰め込まない。
2. **出力先（保存パス）を必ず指定**。書き先が被ると競合する。
3. **入力（顧客名・品目・期日など）を必ず添える**。曖昧だと精度が落ちる。
4. **金額・数量・納期を含むタスクは必ず「人間確認必須」**。AI 出力を直接送らない。
5. **社内ネットワークドライブ・経費精算スクリプトだけは Windows 専用**。Asana / Gmail / カレンダーはクラウドでも使える（MCP 接続済み）。
6. **複数タスクの同時発注はバンドル（B-XXX）を使う**。タブを増やすより速い。定義は `context/ai_operations_flow.md` 参照。

### 寝る前の発注フォーマット
```
[テンプレ名] / 入力: [変数] / 出力先: [パス] / 期限: 朝9時まで
```

例：
```
T-001 見積書ドラフト / 入力: 株式会社○○・SS400 t6.0×1500×3000 100枚 / 出力先: 鉄鋼事業部/営業/見積書/ / 期限: 朝9時
```

## 鉄鋼事業部のテンプレ

### T-001 見積書ドラフト作成
- **目的**: 顧客への見積回答の下書き
- **入力（必須）**: 顧客名・品目（材質・寸法・数量）
- **入力（任意）**: 希望納期・支払条件
- **参照**: `context/customers.md` / `鉄鋼事業部/営業/見積書/` 内の過去案件
- **出力先**: `鉄鋼事業部/営業/見積書/[顧客名]_[YYYYMMDD]_draft.md`
- **人間確認**: **必須**（単価・納期・諸条件すべて）
- **プロンプト例**:
  > 顧客「○○株式会社」向けに、SS400 t6.0×1500×3000 を100枚で見積書ドラフトを作成してください。過去取引があれば customers.md と過去見積を参照し、単価レンジを提示してください。最終的な単価判断は私が行います。

### T-002 商談メモから提案書起案
- **目的**: 商談メモを元に提案書ドラフトを生成
- **入力（必須）**: 商談メモのパス（または本文）
- **参照**: `context/company_profile.md` / 同顧客の過去提案書
- **出力先**: `鉄鋼事業部/営業/提案書/[顧客名]_[テーマ]_draft.md`
- **人間確認**: **必須**（提案内容・金額感）
- **プロンプト例**:
  > `鉄鋼事業部/営業/商談メモ/2026XXXX_株式会社○○.md` を読み込んで、先方の課題に対する提案書ドラフトを起案してください。三幸商事の強みは company_profile.md を参照。

### T-003 顧客向けメール下書き
- **目的**: お礼・依頼・進捗連絡などのメール文面作成
- **入力（必須）**: 宛先・用件
- **参照**: `context/email_context.md`（トーン・署名）
- **出力先**: `鉄鋼事業部/営業/メール/draft_[YYYYMMDD]_[用件].md`
- **人間確認**: 内容確認後、本人が Gmail から送信
- **プロンプト例**:
  > ○○株式会社の山田課長宛に、先日の打合せのお礼と、見積提出予定日（今週金曜）の連絡メールを書いてください。email_context.md のトーンで。

### T-004 鉄鋼マーケット動向リサーチ
- **目的**: 業界動向を朝のインプットとして要約
- **入力（必須）**: 期間（例：直近1週間）
- **参照**: Web 検索（鋼材市況・原料・為替）
- **出力先**: `鉄鋼事業部/マーケティング/market_report_[YYYYMMDD].md`
- **人間確認**: 不要（情報として消費）
- **プロンプト例**:
  > 直近1週間の国内鋼材市況（H形鋼・鋼板・棒鋼）、原料（鉄鉱石・原料炭・スクラップ）、為替の動きを A4 1枚程度で要約してください。三幸商事の主力品目に関連するトピックを優先。

### T-005 競合・業界企業の動向調査
- **目的**: 競合の最新動向・展示会出展情報の収集
- **入力（必須）**: 調査対象（企業名・キーワード）
- **出力先**: `鉄鋼事業部/マーケティング/competitor_[企業名]_[YYYYMMDD].md`
- **人間確認**: 不要
- **プロンプト例**:
  > 「○○商事」の直近半年のプレスリリース・採用情報・取扱品目変更を Web から調べて、三幸商事として注視すべき点を3点抽出してください。

## 缶バッジ事業部 / 三幸プロダクツのテンプレ

### T-101 EC 商品ページ文面作成
- **目的**: 新商品の EC ページ説明文を3パターン生成
- **入力（必須）**: 商品名・仕様・想定顧客層
- **参照**: `缶バッジ事業部/商品・製造/製品カタログ/` の既存商品ページ
- **出力先**: `缶バッジ事業部/ECサイト/商品ページ/[商品名]_draft.md`
- **人間確認**: 価格・在庫情報のみ要確認
- **プロンプト例**:
  > 新商品「ヒンジクリップ Sサイズ・ゴールド」の EC ページ文面を3パターン（機能訴求・デザイン訴求・ギフト訴求）作成してください。文字数は各300字程度。

### T-102 SNS 投稿コンテンツ起案（X / Instagram）
- **目的**: 週次の SNS 投稿7本をまとめて起案
- **入力（必須）**: 対象週・プラットフォーム
- **参照**: `缶バッジ事業部/SNS/運用メモ/` のトーン定義
- **出力先**: `缶バッジ事業部/SNS/投稿コンテンツ/[YYYYMM]_week[N].md`
- **人間確認**: 投稿前に画像と合わせて確認
- **プロンプト例**:
  > 来週分（5/30-6/5）の Instagram 投稿7本を起案してください。テーマ：缶バッジマシンの使い方Tips × 3、新商品紹介 × 2、お客様事例 × 2。トーンは親しみやすく、絵文字は控えめ。

### T-103 EC 受注の一次対応文案
- **目的**: 受注メール・問合せメールへの一次返信文案
- **入力（必須）**: 受注内容またはお問い合わせ内容
- **参照**: `context/email_context.md` / 缶バッジ事業部の FAQ
- **出力先**: `缶バッジ事業部/ECサイト/受注管理/reply_[YYYYMMDD]_[件名].md`
- **人間確認**: 必須（送信前）
- **プロンプト例**:
  > 添付の受注メール（缶バッジマシン Pro 1台 + パーツ3種）に対して、納期確認・送料案内・支払い方法を含む一次返信文案を作成してください。

### T-104 展示会出展準備（ギフトショー等）
- **目的**: 出展準備のタスク分解・チェックリスト作成
- **入力（必須）**: 展示会名・出展テーマ
- **参照**: 過去の展示会資料
- **出力先**: `缶バッジ事業部/マーケティング/展示会資料/[展示会名]_checklist.md`
- **人間確認**: 不要（叩き台として）
- **プロンプト例**:
  > 「第101回東京インターナショナル・ギフトショー春2026」に缶バッジ事業部として出展します。出展2ヶ月前から当日までのタスクを週次でリストアップしてください。

## 全社共通テンプレ

### T-201 Asana タスク朝サマリー
- **目的**: 今日着手すべきタスクを優先順位付きで提示
- **入力（必須）**: 対象日（デフォルト：今日）
- **参照**: Asana MCP（クラウド / Windows どちらも可）
- **出力先**: 画面表示のみ（または `daily/[YYYYMMDD]_asana_summary.md`）
- **人間確認**: 不要
- **プロンプト例**:
  > 今日着手すべき Asana タスクを、期日が近い順 + 重要度順で一覧化してください。各タスクに「何をすればクローズできるか」の一言を添えてください。

### T-202 Gmail 未返信メール要約
- **目的**: 受信トレイから未返信の重要メールを抽出
- **入力（必須）**: 対象期間（例：過去3日）
- **参照**: Gmail MCP（クラウド / Windows どちらも可）
- **出力先**: 画面表示のみ
- **人間確認**: 不要
- **プロンプト例**:
  > 過去3日間の Gmail から、未返信かつ業務関連のメールを抽出し、優先度・要点・推奨返信方針を提示してください。

### T-203 議事録の整形
- **目的**: 録音文字起こしを議事録形式に整形
- **入力（必須）**: 文字起こしテキスト（plaud 等から）
- **参照**: `context/plaud.md`
- **出力先**: `総務・人事部/議事録/[YYYYMMDD]_[会議名].md`
- **人間確認**: 配布前に確認
- **プロンプト例**:
  > 添付の文字起こしを、議事録フォーマット（日時・参加者・議題・決定事項・宿題）に整形してください。発言者の特定が曖昧な箇所は「※要確認」と明記。

### T-204 経費精算書の作成支援
- **目的**: レシート情報から経費精算書を作成
- **入力（必須）**: 経費明細
- **参照**: `expense_report.py`（既存スクリプト）
- **出力先**: `財務・経理部/経費精算/[YYYYMM]_[氏名].xlsx`
- **人間確認**: 必須（金額・勘定科目）
- **プロンプト例**:
  > 添付のレシート画像から経費精算書を作成してください。expense_report.py を使用。

### T-205 業界・経済ニュース朝サマリー
- **目的**: 三幸商事に関連しそうな業界ニュースを朝イチでまとめる
- **入力（必須）**: なし（毎朝定型）
- **参照**: Web ニュースサイト
- **出力先**: 画面表示のみ
- **人間確認**: 不要
- **プロンプト例**:
  > 直近24時間の経済・産業ニュースから、鉄鋼業界・大阪経済・中小企業政策・AI動向に関連する5件を選んで、各1行で要約してください。

## NG パターン（並列起動でやってはいけないこと）

| ダメな例 | なぜダメか | 改善 |
|---------|----------|------|
| 「いい感じにやっといて」 | 入力が曖昧で出力もブレる | テンプレIDと入力変数を明示 |
| 複数セッションで同じ Excel を編集 | ファイル競合・上書きリスク | セッションごとに出力先を分ける |
| 見積書を AI 出力のまま顧客送信 | 単価ミス・条件ミスの責任問題 | **必ず人間確認** |
| 顧客情報を Web 検索エージェントに渡す | 情報漏洩リスク | 社外送信が前提のタスクには customers.md を渡さない |
| 重要メールの返信を完全自動化 | トーン・ニュアンスが商社に合わない | 文案生成までは AI、送信は人間 |

## テンプレ追加のルール

新しい頻出タスクに気づいたら、このファイルに追記する。
形式：
```
### T-XXX タスク名
- **目的**:
- **入力（必須）**:
- **参照**:
- **出力先**:
- **人間確認**:
- **プロンプト例**:
```

番号体系：
- T-001 〜 T-099: 鉄鋼事業部
- T-101 〜 T-199: 缶バッジ事業部 / 三幸プロダクツ
- T-201 〜 T-299: 全社共通

- T-401 〜 T-499: 家計管理

- **人間確認**: **必須**（金額）
- **プロンプト例**:

- **出力先**: `副業_AIxBGM/マーケティング/posts_[曲名].md`
- **人間確認**: 投稿前に確認
- **プロンプト例**:

## 家計管理のテンプレ

### T-401 月次収支まとめ
- **目的**: その月の収入・支出を見える化
- **入力（必須）**: 銀行・カード明細 CSV
- **出力先**: `家計管理/月次収支/[YYYYMM].md`
- **人間確認**: **必須**（数字の正確性）
- **プロンプト例**:
  > 添付の家計データ（5月分）から、収入・固定費・変動費・貯蓄を集計して、前月比と気付きを。

### T-402 固定費棚卸し
- **目的**: サブスク・通信費・保険の見直し候補抽出
- **入力（必須）**: 現在の固定費一覧
- **出力先**: `家計管理/固定費見直し/[YYYYMMDD]_review.md`
- **人間確認**: 削減実行前に確認
- **プロンプト例**:
  > 現在の固定費一覧を見て、削減候補・乗り換え候補・解約候補を提案。優先順位と削減見込み額も。

### T-403 投資判断補助
- **目的**: 投資先候補のリサーチと比較
- **入力（必須）**: 銘柄名・想定金額・投資目的
- **出力先**: `家計管理/投資/[銘柄名]_[YYYYMMDD].md`
- **人間確認**: **必須**（最終判断は本人）
- **プロンプト例**:
  > 「○○ ETF」を 50 万円分検討中。直近1年のパフォーマンス・経費率・分散性・リスクをまとめて、買う/見送る/減額の判断材料を。最終判断は私が行います。

### T-404 大型支出シミュレーション
- **目的**: 不動産・車・教育費などの長期計画
- **入力（必須）**: 想定額・時期・前提条件
- **出力先**: `家計管理/大型支出計画/[項目]_simulation.md`
- **人間確認**: **必須**
- **プロンプト例**:
  > 5年後に住宅購入（4,000万円・頭金1,000万円）を想定。月々のローン・固定費影響・必要貯蓄ペースをシミュレーション。

### T-405 ふるさと納税最適化
- **目的**: 年間枠の使い切り戦略
- **入力（必須）**: 年収・家族構成・控除予定額
- **出力先**: `家計管理/月次収支/furusato_[YYYY].md`
- **人間確認**: 不要
- **プロンプト例**:
  > 年収○○万円・家族構成 ○○ の場合、ふるさと納税の限度額と、コスパの良い返礼品カテゴリーを提案。
