# 竹村翔 AI 個人マスタリー 90 日プラン

> 期間：2026/05/28 → 2026/08/26
> ゴール：Lv.3 → Lv.5（戦略家）
> 原則：社内展開より個人マスタリーが先

---

## レベル定義

- **Lv.1 利用者**：ChatGPT/Claude に質問できる
- **Lv.2 業務組み込み**：日常業務の30%以上で AI を使う
- **Lv.3 ワークフロー設計者**：Claude Code でツール連携を組める ← **現在地（2026/5/28）**
- **Lv.4 エージェント設計者**：部門マネージャー AI を自前で設計できる
- **Lv.5 戦略家**：AI を前提に事業構造を再設計できる

## 関門 / リスク

- **時間配分** — 営業実務との両立。1 日 60 分の「マスタリー枠」を死守
- **社員理解** — 焦って展開せず、まず社長自身が背中で示す（learnings.md 準拠）
- **税務 / 機密** — 副業 BGM 収益・家計データを社内 repo に混入させない／税務判断は税理士に必ず投げる
- **過剰設計** — 「Claude は1人」原則を死守。マネージャー分割は概念のみ、財布は1つ
